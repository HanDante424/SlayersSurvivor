## 1. 작업 범위

이번 전달 내용은 에른 스트레이의 전투 시스템 구현을 위한 최신 기획이다.

현재 다음 3개 스킬의 이미지 리소스가 프로젝트에 추가되어 있다.

1. 파이어 슬래시 (Fire Slash)
2. 트리플 슬래시 (Triple Slash)
3. 솔라 슬래시 (Solar Slash)

리소스의 실제 파일명, 위치, 프리팹 연결 여부는 프로젝트에서 확인해야 한다.

기존 게임 구조는 뱀서라이크 방식으로, 대부분의 공격은 자동 발동하고 일부 스킬과 궁극기만 수동으로 사용한다.

## 2. 스킬별 기본 전투 스펙

| 항목 | 파이어 슬래시 | 트리플 슬래시 | 솔라 슬래시 |
|---|---|---|---|
| 분류 | 자동 | 수동 | 자동 |
| 기본 쿨타임 | 3초 | 8초 | 5초 |
| 기본 피해량 | 10 | 8 × 3타 | 5 + 12 |
| 총 기본 피해량 | 10 | 24 | 17 |
| 공격 방향 | 캐릭터가 보는 방향 | 캐릭터가 보는 방향 | 전방위 |
| 생성 위치 | 캐릭터 방향 기준 | 캐릭터 방향 기준 | 플레이어 중심 |
| 초기 보유 | 기본 무장 | 레벨업 획득 | 레벨업 획득 |

### 2.1 파이어 슬래시

- 에른 스트레이의 기본 무장이다.
- 게임 시작 시 기본 보유한다.
- 자동 공격이다.
- 기본 쿨타임은 3초다.
- 기본 피해량은 10이다.
- 캐릭터가 바라보는 방향으로만 공격할 수 있다.

### 2.2 트리플 슬래시

- 수동 사용 스킬이다.
- 기본 쿨타임은 8초다.
- 1회 사용 시 3번 공격한다.
- 각 공격의 기본 피해량은 8이다.
- 기본 총 피해량은 24다.
- 캐릭터가 바라보는 방향으로만 공격할 수 있다.

### 2.3 솔라 슬래시

- 자동 공격 스킬이다.
- 기본 쿨타임은 5초다.
- 플레이어 중심에서 생성되는 전방위 공격이다.
- 첫 번째 베기 피해량은 5다.
- 베기 이후 발생하는 폭발 피해량은 12다.
- 두 피해는 별개의 타격 판정이다.
- 기본 총 피해량은 17이다.

**공격 순서:**

1. 플레이어 중심에 첫 번째 베기 공격 발생
2. 해당 공격의 피해량 5 적용
3. 후속 폭발 발생
4. 폭발 피해량 12 적용

베기와 폭발 사이의 정확한 시간 간격은 아직 확정되지 않았다.

## 3. 레벨업 및 스킬 획득 시스템

### 3.1 기본 구조

- 기존 뱀서라이크의 경험치 획득 및 캐릭터 레벨업 방식을 채용한다.
- 캐릭터 레벨업 시 기본적으로 무작위 선택지 3개가 등장한다.
- 자동 스킬, 수동 스킬, 패시브 스킬은 동일한 레벨업 선택 시스템에서 등장한다.
- 궁극기는 별도로 지정된 해금 레벨에 도달한 이후 선택지에 등장할 수 있다.

### 3.2 스킬 출현 규칙

- 모든 일반 스킬의 최대 레벨은 15다.
- 15레벨 미만의 일반 스킬은 레벨업 후보에 무작위로 등장할 수 있다.
- 아직 획득하지 않은 스킬을 선택하면 해당 스킬을 신규 획득한다.
- 이미 Lv.1 이상 보유한 스킬을 선택하면 별도의 기본 강화 선택 화면이 표시된다.
- 기본 강화 선택을 완료하면 해당 스킬의 레벨이 1 증가한다.
- Lv.15에 도달한 스킬은 더 이상 일반 레벨업 강화 대상으로 등장하지 않는다.

기본 무장인 파이어 슬래시는 게임 시작 시 이미 보유한 것으로 처리한다.

### 3.3 보유 개수 제한

| 분류 | 최대 보유 |
|---|---|
| 자동 스킬 | 6개 |
| 패시브 스킬 | 6개 |
| 수동 스킬 | 역할군별 1개 |
| 궁극기 | 캐릭터별 2종 기획 중 |

수동 스킬의 역할군 목록과 궁극기 동시 보유 규칙은 아직 확정되지 않았다.

## 4. 기본 강화 시스템

이미 보유한 일반 스킬이 레벨업 후보로 선택되면 다음 3개 강화 중 하나를 선택할 수 있다.

| 강화 종류 | 1회 선택 효과 |
|---|---|
| 공격력 강화 | 해당 스킬 피해량 +10% |
| 범위 강화 | 해당 스킬 공격 범위 +10% (2026-11-09 +5% → +10% 상향) |
| 쿨타임 강화 | 해당 스킬 쿨타임 -5% |

강화는 해당 스킬의 기본 성능을 기준으로 계산한다.

### 4.1 모든 스탯 강화는 합연산

강화율끼리 곱하지 않는다.

**피해량 계산**

`최종 피해량 = floor(기본 피해량 × (1 + 공격력 증가율 합계))`

- 피해량 소수점 이하를 내림 처리한다.
- 타격이 여러 개인 스킬은 각 타격의 피해량을 별도로 계산한다.

예시:

파이어 슬래시 피해량 10, 공격력 강화 3회 적용 시

`floor(10 × (1 + 0.1 × 3)) = 13`

트리플 슬래시 피해량 8 × 3타, 공격력 강화 2회 적용 시

`floor(8 × 1.2) = 9`

최종 피해량은 `9 × 3타 = 27`이다.

**범위 계산**

`최종 범위 = 기본 범위 × (1 + 범위 증가율 합계)`

범위에 대한 별도 정수화 규칙은 아직 정해지지 않았다.

**쿨타임 계산**

`최종 쿨타임 = 기본 쿨타임 × (1 - min(쿨타임 감소율 합계, 0.9))`

- 쿨타임 감소 최대 한도는 90%다.
- 90% 감소 시 최소 쿨타임은 기본 쿨타임의 10%다.
- 각 강화율은 합산한다.

예시:

파이어 슬래시 기본 쿨타임 3초, 쿨타임 강화 4회 선택 시

`3 × (1 - 0.05 × 4) = 2.4초`

쿨타임 감소율 합계가 95%에 도달하더라도 90%만 적용하므로, 파이어 슬래시의 최소 쿨타임은 0.3초다.

## 5. 특수 강화 시스템

모든 일반 스킬은 다음 레벨에서 특수 강화가 발생한다.

| 스킬 레벨 | 강화 |
|---|---|
| Lv.5 | 1차 특수 강화 |
| Lv.10 | 2차 특수 강화 |
| Lv.15 | 3차 특수 강화 |

특수 강화는 일반 강화와 동시에 적용된다. 다만 **선택 화면은 순차적으로 진행**한다.

### 5.1 특수 강화 발생 시 처리 순서

예시: 파이어 슬래시 Lv.4 → Lv.5

1. 캐릭터 레벨업 화면이 열린다.
2. 무작위 스킬 후보 3개 중 파이어 슬래시를 선택한다.
3. 기본 강화 선택 화면을 출력한다.
4. 공격력 +10%, 범위 +10%, 쿨타임 -5% 중 하나를 선택한다.
5. 기본 강화가 확정되고 파이어 슬래시 레벨이 4에서 5로 증가한다.
6. Lv.5 특수 강화 조건을 확인한다.
7. 특수 강화 선택 화면을 출력한다.
8. 플레이어가 특수 강화 하나를 선택한다.
9. 기본 강화와 특수 강화가 모두 적용된 최종 스탯을 반영한다.
10. 일반 게임 진행으로 복귀한다.

### 5.2 일반 레벨업과의 차이

- Lv.2~4, Lv.6~9, Lv.11~14: 기본 강화 선택 후 종료
- Lv.5, Lv.10, Lv.15: 기본 강화 선택 후 특수 강화 선택
- 특수 강화 선택을 위해 별도의 캐릭터 레벨업 횟수를 소모하지 않는다.
- 특수 강화 선택은 해당 일반 강화 선택에 이어서 처리한다.

특수 강화 효과는 일반 강화 효과를 대체하지 않는다.

### 5.3 특수 강화 효과

특수 강화의 구체적인 목록은 아직 기획되지 않았다.

현재 확정된 것은 특수 강화의 발생 레벨 및 선택 방식이다.

검토 가능한 특수 강화 유형은 투사체 개수 증가, 스킬 발동 횟수 증가 등이다. 이러한 예시를 개별 스킬의 확정 효과로 간주해서는 안 된다.

특수 강화 선택지 개수도 미정이다.

## 6. 스킬 공격 판정

현재 다음 원칙을 적용한다.

- 공격 방향은 스킬마다 개별 설정한다.
- 파이어 슬래시와 트리플 슬래시는 캐릭터가 바라보는 방향으로만 공격한다.
- 솔라 슬래시는 플레이어 중심에서 전방위로 공격한다.
- 실제 타격 판정의 크기와 위치는 플레이 테스트를 진행하며 조정한다.

따라서 타격 판정의 세부 수치, 콜라이더 크기, 공격 판정 지속시간 등을 현재 기획에서 임의로 확정하지 않는다.

## 7. 기존 궁극기 공통 규칙

- 캐릭터마다 궁극기 2종을 구상한다.
- 궁극기 최초 획득 가능 레벨은 잠정 Lv.45다.
- 궁극기 강화 가능 레벨은 잠정 Lv.60이다.
- 궁극기는 레벨업 선택지에서 획득하거나 강화한다.
- 적 처치 수에 따라 궁극기 게이지를 획득한다.
- 게이지 최대 충전 시 수동 발동할 수 있다.

궁극기의 구체적인 게이지 수치, 동시 보유 규칙, 강화 단계는 미정이다.

## 8. 구현 시 주의사항

- 기본 스킬 수치를 임의로 변경하지 말 것.
- 스킬 레벨 최대치는 15다.
- 캐릭터 레벨과 스킬 레벨을 구분할 것.
- Lv.5·10·15 특수 강화는 스킬 레벨 기준이다.
- Lv.45·60 궁극기 조건은 캐릭터 레벨 기준이다.
- 기본 강화 선택이 끝나기 전에 특수 강화 선택 화면을 띄우지 말 것.
- 특수 강화 레벨에서도 일반 강화가 누락되지 않도록 할 것.
- 공격력 증가율, 범위 증가율, 쿨타임 감소율은 각각 합연산으로 처리할 것.
- 다단히트 스킬은 개별 타격의 최종 피해량을 내림 처리할 것.
- 미확정 특수 강화 효과를 임의로 구현·확정하지 말 것.
- 현재 기획된 3개 스킬 이외의 전체 스킬셋을 이번 구현 범위로 자동 확대하지 말 것.

## 9. 이번 단계의 완료 기준

- 파이어 슬래시가 에른 기본 무장으로 시작한다.
- 파이어 슬래시가 3초마다 바라보는 방향으로 자동 공격한다.
- 트리플 슬래시가 수동 입력 시 바라보는 방향으로 3회 공격한다.
- 솔라 슬래시가 5초마다 플레이어 중심에서 베기와 폭발을 순차 실행한다.
- 캐릭터 레벨업 시 기본 3개 선택지가 나타난다.
- 보유한 스킬을 선택하면 기본 강화 선택 화면이 나타난다.
- 기본 강화 1개를 선택하면 스킬 레벨이 1 증가한다.
- Lv.5·10·15에 도달하면 특수 강화 선택 화면이 이어진다.
- 공격력·범위·쿨타임 강화 수치가 합연산으로 적용된다.
- 피해량은 내림 처리한다.
- 쿨타임 감소율은 최대 90%로 제한한다.
- 스킬별 실제 타격 판정은 플레이 테스트를 통해 조정할 수 있다.

본 문서는 기획 기준이며, 실제 구현 완료 여부를 의미하지 않는다.
