## 0. 공통 규칙
- **분류**: 자동 (쿨타임마다 자동) · 수동 (J / K / L, 획득 순서대로) · 이동 (Space) · 패시브 · 궁극기 (Q, 게이지)
- **피해 계산**: 초기 피해량 → 피해량(%) → 추가 피해량 → 최종 피해량(%) → (대상) 받는 최종 피해량 → 내림
- **피해 종류**: 직접 · 지속 · 특수 · 고정 / **사용 구분**: 직접 사용 (스킬 본체) · 간접 사용 (파생 공격 — 터렛 공격, 추가 투사체 등)
- **성장**: 레벨업 → 스킬 선택 → **기본 강화** 3택 1 (공격력 증가 '피해량' +10% · 범위 증가 '범위' +10% · 쿨타임 감소 '쿨타임 감소' +2.5%, 합연산, 최종 감소 최대 90%) → 스킬 Lv +1
  - 패시브는 공통 기본 강화 대신 **고유 강화** 3종
  - 스킬 **Lv.5 · 10 · 15** 에 **특수 강화** 3택 1 (이전 단계 유지 · 중첩). Lv.15 = 최대
- **결합**: '피해량' · '지속 시간' % = 합연산, '최종 피해량' · '쿨타임' 효과 = 효과마다 독립 배율 곱연산

- Lv15: 고속 방전 (투사체 +2 · 공격 간격 -20%) / 낙뢰 발생 (플레이어 주변 낙뢰로 변경, 도탄 1당 최종 피해량 · 범위 +25%) / 최대한 많이

**LM01 터렛 강화**
- Lv5: 윤활유 (공격 간격 -10% 부여) / 화력 증강 (피해량 +50% 부여) / 내구성 개선 (터렛 지속 +5초 부여)
- Lv10: 초점 맞추기 (터렛 사거리 +50%) / 추가 발사 (투사체 +1 부여) / 장기 정비 (강화 지속 +5초)
- Lv15: 동기화 (강화된 터렛이 직접 피해마다 터렛 스킬 남은 쿨타임 감소) / 자동 관리 프로토콜 (강화 지속만큼 터렛 지속 부여, 터렛마다 1회) / 병렬 출력 (강화된 터렛 1개당 최종 피해량 +20%)

**LM02 지면 강타**
- Lv5: 대지 강타 (피해량 · 범위 +50%) / 지진 (간접 · 특수 피해 + 이동 속도 감소) / 분쇄의 일격 (기절 적 최종 피해량 +50%)
- Lv10: 충격 흡수 (적중 1명당 남은 쿨타임 2% 감소) / 방어구 파괴 (상태이상) / 충격 확장 (넉백 +50% · 범위 +25%)
- Lv15: 지각 변동 (피해량 · 범위 +100%, 쿨타임 +50%) / 붕괴의 낙인 (간접 · 특수 피해) / 연쇄 충격 (간접 · 특수 피해)

**LM03 포격 실시**
- Lv5: 연속 발사 (투사체 +10) / 고폭 (피해량 +50% · 범위 +25%) / 자기장 발생 (이동 속도 감소)
- Lv10: 다연장 (투사체 +10) / 철갑탄 (기절) / 네이팜탄 (간접 · 지속 피해)
- Lv15: 호밍 미사일 (범위 안 적을 겹치지 않게 노림) / 집속탄 (공중 분리 3발, 최종 피해량 -40% · 범위 -30%) / 집중 포격 (포격 범위 -50%, 최종 피해량 +100%, 폭발 범위 +25%)

**LM04 터렛 과부화**
- Lv5: 출력 증폭 (최종 피해량 +50% 부여) / 고속 구동 (공격 간격 -10% 부여) / 냉각 (터렛 남은 지속 +20% · 쿨타임 감소 +10%)
- Lv10: 추가 발사 (투사체 +1 부여) / 재활용 (효과 받은 터렛 소멸 시 설치 스킬 남은 쿨타임 -2.5%) / 융해 (상태이상)
- Lv15: 오버 클럭 (남은 지속 -50%, 최종 피해량 +100%, 공격 간격 -50% 부여) / 자폭 프로토콜 (간접 · 특수 피해) / 집중 포화 (적중 시 그 터렛 최종 피해량 +5%, 5초, 최대 10스택)

**LP01 공구 벨트**
- Lv5: 예비 공구 (투척 투사체 +1) / 관통 (투척 관통 +1) / 묵직한 공구 (투척 피해량 +30%)
- Lv10: 도탄 (투척 도탄 +1) / 골통 부수기 (기절 적에게 투척 최종 피해량 +30%) / 재활용 (투척으로 처치 시 그 스킬 남은 쿨타임 -5%)
- Lv15: 과잉 장전 (투척 직접 사용 3회마다 다음 투척 투사체 +5) / 표적 지시 (투척 직접 피해 시 '표적' 5초, 표적 적은 터렛에게 받는 최종 피해량 +25%) / 투척 마스터 (투척 최종 피해량 · 범위 +50%)

**LP02 자동화 공정**
- Lv5: 연속 설치 (설치 스킬 발동 +1) / 신속 가동 (소환 즉시 공격, 소환 후 3초 공격 간격 -15%) / 탐지 개선 (터렛 사거리 +30%)
- Lv10: 빠른 재구성 (터렛 소멸 시 같은 스킬 남은 쿨타임 -15%) / 동기화 (터렛 1개당 모든 터렛 피해량 +10%) / 요새화 (지속된 1초당 피해량 +10%)
- Lv15: 양산 개시 (설치 발동 +2, 지속 -25%) / 장기 가동 (지속 +100%, 설치 쿨타임 ×1.5) / 전탄 발사 (터렛 투사체 +2, 공격 간격 +30%)

**LP03 충격 역학**
- Lv5: 편두통 (이동 속도 감소) / 약점 노출 (기절 적 받는 최종 피해량 +15%) / 범위 충격 (직접 사용 기절이 주변으로 퍼짐)
- Lv10: 부서진 두개골 (기절 총 지속 1초당 받는 최종 피해량 +10%) / 재기절 (기절 중 기절 시 +0.1초) / 진압 순환 (기절 적 처치 시 기절 스킬 남은 쿨타임 -2.5%)
- Lv15: 과잉 진압 (기절 적 받는 최종 피해량 +30%) / 충격 잔향 (간접 · 특수 피해, 반경 2 [임시]) / 제압우위 (기절 적 1명당 모든 스킬 최종 피해량 +5%, 최대 +50%)
