- 특수 강화 화면: `{스킬} 1차/2차/3차 특수 강화` / `스킬 Lv.{n} 도달`, 기획 미설계 시 "확인 — 특수 강화 효과는 아직 기획되지 않았습니다 (적용되는 효과 없음)"
- 경고 확인: "그래도 {강화} 선택" / "취소 — 다른 특수 강화를 고릅니다"
- 레벨업 카드: `{스킬}  Lv.{a} → {b}  [분류]` + "★ Lv.{n} 특수 강화", 패시브는 "고유 강화 선택: …", 궁극기는 "궁극기 강화", 신규는 `(신규)` + 설명 + 키 안내
- HUD 배지: 파이어 스트림 스택 수, 블레이징 스톰 게이지 %, 흡수 가열 `{스택}/{최대}` · `{스택}★`, 옥염 `살육 {n}`
