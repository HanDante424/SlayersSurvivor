## 1. 키워드 (인게임 표기에도 사용)

### 1.1 피해 계산 단계
| 키워드 | 의미 | 결합 |
|---|---|---|
| **초기 피해량** | 스킬·패시브에 지정된 기본 수치. 기본 수치를 올리는 고정값 강화도 여기 (예: 화상 초당 '초기 피해량' +2) | 합 |
| **피해량** | % 증가·감소. 같은 대상에 붙는 것끼리 합연산 | 합 → 곱 1회 |
| **추가 피해량** | 피해량 % 적용 **이후** 더하는 고정 수치. % 영향을 받지 않음 | 합 |
| **최종 피해량** | 독립 효과마다 배율 하나. 서로 **곱연산**. 그 효과의 수치를 올리는 기본 강화(+%p)는 해당 효과 안에서 합연산 | 곱 |
| **받는 최종 피해량** | 대상(적) 쪽 배율. 공격자 쪽 최종 피해량까지 계산한 뒤 피해 전달 시 적용 (예: 융해) | 곱 |
| 내림 | 대상 단계까지 끝난 뒤 피해 이벤트마다 1회 | |

예) 옥염 기본 30% + 최종 피해 강화 2%p × 4 = ×1.38, 극한 연소 ×1.75 → **×2.415** (= 최종 피해량 +141.5%).
인게임 표기는 **증가율 방식**("최종 피해량 +141.5%"), 상세 정보에서만 배율 병기.

### 1.2 피해 유형 (원인)
| 키워드 | 의미 |
|---|---|
| **직접 피해** | 플레이어 공격의 직접 적중. 화염의 검 화상 부여, 살아있는 폭탄·화염 낙인 트리거 |
| **지속 피해** | 디버프·장판·지속형 공격 (화상, 살아있는 폭탄 폭발, 일촉즉발, 타오름, 잔화의 검흔). 소각 트리거 |
| **아이템 피해** | 아이템으로 발생 |
| **특수 피해** | 소각 등. **어떤 트리거도 발동시키지 않음** (직접·지속·아이템 피해 트리거 모두) |

### 1.3 피해 특성
| 키워드 | 의미 |
|---|---|
| **고정 피해** | 피해량·최종 피해량·받는 최종 피해량 등 **모든 증감 무효**. 참조값은 참조 대상의 규칙으로 계산하되 생성된 고정 피해는 다시 증폭하지 않음 |

### 1.4 발동 구분
| 키워드 | 의미 |
|---|---|
| **직접 발동** | 플레이어가 최초로 발동시키는 스킬 (자동 스킬의 쿨타임 발동, 수동 스킬 입력) |
| **간접 발동** | 연쇄 작용으로 발동 (죽음의 메아리, 솔라 슬래시 메아리 재발동, **츠바메가에시 추가 발동**) |

## 2. 피해 계산 · 전달 구조

```
① 공격자 단계 (스킬에서 1회, 대상과 무관)
   초기 피해량 → × (1 + 피해량 합) → + 추가 피해량 → × 최종 피해량 배율들
   = "스킬 최종 피해량" (잔화의 검흔이 참조하는 값)
② 대상 단계 (맞은 적마다 한 번 더 계산)
   × 대상 의존 최종 피해량 (고열 절삭: 그 적의 화상 스택 합계당 +5%, 내부 합연산)
   × 받는 최종 피해량 (융해)
   → 내림 → 체력 감소
   + 대상 의존 고정 피해 (강제 발화)
③ 전달 후 트리거 (피해 유형별)
   직접 피해: 화상 부여, 살아있는 폭탄, 화염 낙인, 화염 공명(직접 발동), 빠른 준비
   지속 피해: 소각
   처치: 죽음의 메아리, 확산되는 불길, 살육의 열기, 불길의 순환
```

- 화상은 **화염의 검 패시브 소유의 독립 피해**. 화상을 건 스킬의 강화(스킬 한정 피해량 등)는 받지 않음.
  화상에 적용되는 것: 화염의 검 자체 강화, '화상'/'지속 피해' 대상 효과, 전체 최종 피해량(옥염 등), 받는 최종 피해량.
- 옥염 등 "전체" 최종 피해량은 **고정 피해를 제외한 모든 피해**(직접·지속·아이템·특수 중 고정 아닌 것)에 적용.

## 3. 쿨타임

```
최종 쿨타임 = 기본 × (1 − 기본 강화 감소 합) × 독립 배율 A × 독립 배율 B × …
            단, 결과는 기본의 10% 미만 불가 (최종 감소 90% 상한)
```
- 스킬 기본 강화 쿨타임 감소: 해당 스킬 안에서 합연산 → 배율 1개.
- 그 외 쿨타임 효과(감소·**증가 모두**)는 독립 배율로 **곱연산**: 플레어 ×0.75, 메아리 ×1.25, 초신성 ×1.5, 과부화 ×1.25, 옥염 기동력 강화(내부 합 n×2%), 흡수 가열(스택당 1%, 내부 합) …
  - 예) 기본 10초, 전체 쿨타임 감소 10% + 기본 강화 10% → 10 × 0.9 × 0.9 = **8.1초**. 기본 강화 15%가 되면 10 × 0.9 × 0.85 = **7.65초**
  - 예) 기본 강화 −50% + 초신성 → 5 × 0.5 × 1.5 = 3.75초
- 빠른 공격(남은 쿨타임 ×0.5)도 독립 배율.
- **남은 쿨타임 감소**(빠른 준비, 불길의 순환): 그 시점의 남은 시간 기준, **90% 상한과 무관**.
- 묵직한 일격의 "무효화된 최종 쿨타임 감소율"처럼 상태에 따라 바뀌는 값은 **실시간 변동** (흡수 가열 스택 등 반영).

## 5. 트리플 슬래시
- 빠른 준비: 피해가 **적 1명에게 적용될 때마다** 남은 쿨타임 2.5% 감소.
- 일섬: 공격 횟수 1회당 피해량 +125%. 기본 3타 → 1타 38 (8 × 4.75), 난도질 9타 → 1타 98 (8 × 12.25).
- 츠바메가에시 추가 2회 = **간접 발동**.
- 잔화의 검흔: 스킬 최종 피해량(①, 대상 의존 효과 제외)의 20%를 **고정 피해**로. 화상 미부여.
- 일섬 전용 이펙트: `Resources/Sprites/ErnStray_SkillTripleSlashIlseom.png` (2×3, 6프레임, 약 45° 대각선 → 각도 보정 필요).
- 구현 순서: **화염의 검 먼저**, 그 다음 트리플 슬래시 특수 강화.

**구현 메모 (2026-11-10, `TripleSlash.cs`)** — [해석]은 결정 기록에 없어서 구현에서 정한 것
- AttackCount = 3 × (1 + 난도질 2) / 일섬이면 1. SkillCastCount = 1 + 츠바메가에시 2. 첫 발동 = 직접 발동, 추가분 = 간접 발동
- 난개: 공격마다 바라보는 방향 + ±120°
- 일섬: 피해량 +125% × (일섬 전 공격 횟수). 전용 이펙트(`ErnStray_SkillTripleSlashIlseom`, 2×3)를 공격 방향 − 45° 로 회전
- 고열 절삭: `DamageInfo.perTarget` (대상 단계). 스택은 **이번 타격의 화상이 쌓이기 전** 값
- 빠른 준비: `Enemy.AfterDamaged`. **확정**: 트리플 슬래시 **직접 피해**(공격 적중)만 — 잔화의 검흔·강제 발화 피해는 제외
- 강제 발화: `Enemy.Damaging` (같은 피해의 트리거보다 먼저). `FlameSword.TotalBurnDamage` = 틱 수 × **내림한** 1틱 피해 (1틱 = 화상 강화·옥염 등 공격자 단계 반영).
  **확정 (2026-11-10)**: 이번 타격으로 쌓이는 스택은 **포함하지 않음** (예시 5스택 → 120), 틱마다 내림해 합산 (4.5 × 3틱 → 12). 고정 피해라 받는 최종 피해량(융해) 미적용.
  [해석] 피해 유형 = **특수 피해** (트리거 없음 — 직접 피해로 두면 화상 부여·강제 발화가 다시 걸려 무한 반복)
- 잔화의 검흔: 참조값 = 마지막 공격 1타의 스킬 최종 피해량(대상 의존 효과 제외) × 20%, 고정 피해 · 지속 피해(소각 트리거 O, 화상 X). 생성 후 1초마다 3회.
  [임시] 위치 = 이번 사용의 마지막 공격 3개, 공격 방향이 1~2개뿐이면(일섬) 마지막 방향을 ±25° 로 벌림. 츠바메가에시여도 사용 1번에 3개
- [임시] 난도질 공격 간격 = 기본 간격 × 2 / (횟수 − 1) (한 번 사용 시간을 기본 3타와 비슷하게), 츠바메가에시 발동 사이 0.12초

## 6. 화염의 검 · 화상
| 항목 | 확정 |
|---|---|
| 화상 피해 | 모든 지속 피해는 `초당 피해 × 스택` |
| 부여 | 직접 피해 1타마다 1스택 (다단히트는 타격마다) |
| 갱신 | 재부여 시 모든 스택의 지속시간 함께 갱신. **피해 간격 타이머는 초기화하지 않음** |
| 첫 틱 | 부여 후 피해 간격(기본 1초)이 지난 뒤 |
| 피해 간격 | 지속 피해 기본 1초 (간격 변경은 효과로 명시) |
| 종료 | 지속시간 종료 시 모든 스택 삭제 |
| 소수점 | 내림 (구현에서 처리) |
| 기본 강화 "화상 피해" | 화상 초당 **'초기 피해량' +2** |
| 화상 % 증감 | 모든 '화상' '피해량' 증감은 '피해량' 단계 |
| 지속시간 | `(기본 3초 + 고정 증가) × (1 + % 증가 합)` — 피해량과 같은 중간 단계 방식. 예) +1초 ×2 + 기름붓기 → (3+2)×2 = 10초 |
| 융해 | 화상 스택당 '받는 최종 피해량' +2% (대상 단계) |
| 확산되는 불길 | 적 사망 시 반경 3(임시) 안 적에게 화상 1스택 |
| 일촉즉발 | 최대 스택 도달 시 `스택 × 초당 피해 × 남은 시간` 을 지속 피해로 즉시 적용, 스택 0 |
| 살아있는 폭탄 | 폭발 = '화상' '지속 피해' (초당 피해 × 스택). 직접 피해가 아니므로 화상·폭탄 재발동 없음. 범위 임시값 |
| 영원의 불꽃 | 지속시간은 스탯으로 존재, 화상 적용은 영구. 이후 지속시간 증가의 영향과 그에 따른 1초당 피해량 +50% 도 실시간 반영. 강제 발화는 이 스탯 지속시간 사용 |
| 화염 낙인 | 화상이 사라지면 함께 사라짐 |
| 표시 | `BurnFx.Show / Stop` (화상 표시 파티클, PR #9) 을 화상 상태에 연결 |

**구현 메모 (2026-11-10, `ErnPassives.cs` `FlameSword`)** — [해석]은 결정 기록에 없어서 구현에서 정한 것
- 화상 1틱 = 초기 피해량 `(2 + 2n) × 스택` → 피해량 (기름붓기 −25% · 핵융합 · 영원의 불꽃 · 화염 낙인 · 전역) → 최종 피해량 (전역) → 받는 최종 피해량 (융해) → 내림. 유형 '지속 피해', 태그 '화상', 출처 = 화염의 검 (간접 발동)
- 화상 부여 트리거: `Enemy.Damaged` 의 직접 피해 + 타오름(`canBurn`). 같은 피해에서 순서 = 화염 낙인 +1 → 살아있는 폭탄 → 화상 1스택 (낙인·폭탄은 "이미 화상 상태"일 때만)
- [해석] 확산되는 불길: **화상 상태로** 죽은 적만 확산. 반경은 `SkillTuning.flameSpreadRadius`(3). 연쇄가 한 프레임 재귀로 쌓이지 않게 다음 Tick 에 처리
- [해석] 살아있는 폭탄: 폭발 피해 = 맞은 적의 화상 1틱 (그 적의 낙인 포함). 반경 `flameBombRadius`(1.5, 임시). 폭발 중심의 적도 맞음. 이번 직접 피해로 죽었어도 폭발
- 일촉즉발: `(남은 시간 / 피해 간격) × 틱 피해`. [해석] 영원의 불꽃이면 남은 시간 = 지속시간 스탯
- **확정 (2026-11-10, 사용자 "지금대로")**
  1. 확산되는 불길은 화상 상태로 죽은 적만 확산 → 일촉즉발로 죽은 적은 확산하지 않음 (스택을 먼저 소모)
  2. 일촉즉발의 남은 시간 = 최대 스택 도달 시 갱신된 뒤의 값 (사실상 지속시간 전체)
  3. 일촉즉발 피해에는 융해가 붙지 않음 (스택 소모 후 피해 적용)
- 끈적한 화염: `Enemy.statusSpeedMul` = 0.5 (슬로우 배율과 곱연산)
- 핵융합: 실제 지속시간 = min(스탯, 3초), 피해량 +100% × (스탯 − 3)
- 지속 피해 틱은 넉백을 건드리지 않음 (`Enemy.NoKnock`)
- 패시브 고유 기본 강화: `Skill.PassiveBasicOptions` (공통 기본 강화 대신)

## 7. 옥염
| 항목 | 확정 |
|---|---|
| 최종 피해량 효과 | 기본 30%(+기본 강화 2%p씩 합), 화력 증폭 30%, 극화 50%, 극한 연소 75% → **각각 독립 배율, 곱연산** |
| 겁화 / 홍련지옥 | 화상 최종 피해량 ×1.5 / ×2 → 곱연산 (둘 다면 ×3) |
| 적용 범위 | 고정 피해를 제외한 모든 피해 |
| 지속 피해 강화 | '지속 피해' '피해량' +10% (피해량 단계) |
| 기동력 강화 | 쿨타임 감소는 옥염 내부 합 → 독립 쿨타임 배율 1개 |
| 살육의 열기 | 처치할 때마다 모든 스택 지속시간(5초) 갱신. 스택 내부 합연산 → 배율 1개 |
| 불길의 순환 | 처치 시 자동·수동·**이동** 스킬 남은 쿨타임 ×0.95. 궁극기 제외. 이동 스킬은 **충전 중인 스택** 기준 |
| 소각 | '특수 피해' + 고정 피해. 스택과 무관하게 **지속 피해 틱마다** 1회. 지속 피해 출처가 여럿이면 각 틱마다 발동 |
| 화염 공명 | **'직접 발동'으로 적중 시** 궁극기 게이지 +1%. 발동 1번당 1회 (공격 개수·맞은 적 수 무관) |

**구현 메모 (2026-11-10, `Hellfire.cs`)**
- 옥염의 모든 피해 효과는 `CombatModifier` 하나로 등록: 최종 피해량(고정 피해 제외) · '지속 피해' 피해량 · 쿨타임 독립 배율
- 발동 식별: 직접 발동마다 `Skill.BeginCast()` 가 번호(`castId`)를 매기고, 그 발동에서 나온 피해(지연 공격·지속 피해 포함)가 같은 번호를 가짐. 간접 발동·화상 틱은 0
- 기동력 강화 이동속도: `Player.moveSpeedMul` 에 옥염 몫만 곱함 (다른 이동속도 효과와 곱연산)
- 소각: 지속 피해가 적용된 직후, 대상이 살아 있으면 1회. 특수 피해라 다른 트리거 없음
- 살육의 열기 스택은 HUD 스킬 칸 배지에 "살육 n" 으로 표시. 배율은 피해가 만들어지는 순간 값 (투사체 · 지속 공격 틱은 발동 시점, 화상 틱은 매 틱)
- **확정 (2026-11-10, 추천대로)**
  1. 화염 공명: 직접 발동 + **'직접 피해'가 적중**했을 때만 (직접 발동 스킬의 지속 피해만 맞으면 충전 없음)
  2. 소각: 고정 피해 **최소 1**
  3. 화염 공명: 궁극기(블레이징 스톰) 적중은 제외
- 지연 공격(삼연발 · 검기 · 연속 공격 · 트리플 슬래시 2·3타 · 솔라 폭발)은 발동 시점의 번호를 그대로 사용 (`Skill.CastRef`)
- 타오름은 지속 중 `Casting` → 남은 쿨타임 감소(불길의 순환)는 지속이 끝난 뒤의 쿨타임에만 적용

## 8. 솔라 슬래시
- 타오름 = **'지속 피해'**. 예외로 화염의 검 화상 부여 가능.
- 플레어 = '최종 피해량' +50%, 쿨타임 ×0.75. 메아리 쿨타임 ×1.25, 초신성 쿨타임 ×1.5 (곱연산).
