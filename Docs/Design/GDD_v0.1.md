# 1. 게임 기본 기획

## 1.1 장르 및 전투 방향

**장르: 뱀서라이크 기반 2D 액션 게임**

기존 뱀서라이크의 전투 및 성장 방식을 채용한다.

- 공격의 대부분은 자동으로 발동한다.
- 특정 액티브 스킬은 플레이어가 수동 사용한다.
- 궁극기는 수동 발동한다.
- 적을 처치하고 경험치를 획득하여 레벨업한다.
- 레벨업 시 무작위로 등장하는 스킬 후보 중 하나를 선택한다.
- 선택을 통해 신규 스킬을 획득하거나 기존 스킬을 강화한다.
- 캐릭터마다 독립된 고유 스킬셋을 보유한다.

※ 정확한 조작키, 공격 대상 선정 알고리즘, 플레이 시간, 스테이지 구성은 아직 확정하지 않았다.

## 1.2 초기 플레이어블 캐릭터

| 캐릭터 | 속성 | 전투 방식 | 범위 | 속도 | 특징 |
|---|---|---|---|---|---|
| 에른 스트레이 | 화염 | 검술 | 중간 | 빠름 | 고속 검술 중심 |
| 스티움 카터렉 | 어둠 | 특대검 | 중간 | 느림 | 높은 위력, 높은 내구성 |
| 멜 발렌티나 | 전 속성 | 마법 | 넓음 | 빠름 | 높은 위력, 낮은 내구성 |

세 캐릭터는 동일한 성장 시스템을 공유하지만 스킬셋은 각각 독립적으로 구성한다.

에른의 기본 공격 위력과 내구성은 아직 수치 또는 상대적 등급으로 확정되지 않았다.

# 2. 공통 스킬 시스템

## 2.1 스킬 종류 및 슬롯

| 스킬 종류 | 보유 제한 | 발동 방식 |
|---|---|---|
| 자동 스킬 | 최대 6개 | 자동 |
| 패시브 스킬 | 최대 6개 | 상시 적용 |
| 수동 스킬 | 역할군별 1개 | 수동 |
| 궁극기 | 캐릭터별 2종 구상 | 게이지 충전 후 수동 |

**수동 스킬 역할군은 아직 확정되지 않았다.**

현재 돌진, 피해, 군중제어, 이동 등의 유형이 언급되었으나 정식 역할군 분류 및 슬롯 구조는 미정이다.

궁극기 2종은 캐릭터별 기획 목표이며, 동시에 2개를 장착할 수 있는지는 정해지지 않았다.

## 2.2 일반 스킬 성장

**스킬 최대 레벨: 15**

일반 레벨업으로 강화되는 요소:
- 피해량
- 재사용 대기시간
- 공격 범위
- 기타 해당 스킬의 수치적 성능

특수 강화 시점:

| 스킬 레벨 | 효과 |
|---|---|
| Lv.5 | 1차 특수 강화 |
| Lv.10 | 2차 특수 강화 |
| Lv.15 | 3차 특수 강화 |

특수 강화 예시:
- 투사체 수 증가
- 스킬 발동 횟수 증가
- 스킬 고유 기능의 구조적 확장

각 스킬의 구체적인 특수 강화 효과는 별도 설계한다.

특수 강화 시 기본 수치 강화가 동시에 적용되는지는 미정이다.

## 2.3 레벨업 선택 시스템

**기본 선택지: 3개**

레벨업 시 다음 종류의 스킬이 함께 무작위 후보로 등장한다.

- 자동 스킬
- 수동 스킬
- 패시브 스킬
- 조건을 충족한 궁극기

신규 획득과 기존 스킬 강화가 선택지에 등장하는 구조다.

자동 공격 방향 및 타겟팅 방식은 스킬별로 별도 설정한다.

현재 미정인 항목:
- 후보별 출현 확률
- 최대 레벨 스킬의 후보 제외 규칙
- 슬롯이 가득 찼을 때의 후보 처리
- 새로고침·선택지 제외 등의 보조 시스템
- 캐릭터 최대 레벨 및 경험치 곡선

# 3. 궁극기 시스템

## 3.1 해금 및 강화

| 조건 | 설정 |
|---|---|
| 최초 획득 가능 레벨 | 캐릭터 Lv.45 |
| 강화 가능 레벨 | 캐릭터 Lv.60 |
| 획득 방식 | 레벨업 선택지 |
| 강화 방식 | 조건 달성 후 레벨업 선택지 |
| 게이지 충전 | 적 처치 수 기반 |
| 사용 조건 | 게이지 최대 충전 |
| 사용 방식 | 수동 발동 |

Lv.45와 Lv.60은 **현재 잠정 설정**이다.

레벨에 도달하면 선택 가능해지는 것이며, 레벨 도달 즉시 자동 획득·강화되는 것은 아니다.

## 3.2 미확정 규칙

- 게이지 최대 수치
- 적 1마리당 게이지 획득량
- 강한 적·보스 처치 시 추가 게이지 유무
- 궁극기 2종 중 선택 또는 동시 보유 여부
- 궁극기별 게이지 공유 여부
- 궁극기 최대 강화 단계
- 게이지 사용 및 초기화 방식

### A05. 파이어 블레이드 (Fire Blade)

- 분류: 자동
- 공격 범위: 중간
- 쿨타임: 김
- 총 피해량: 높음

**작동 방식**

1. 지정 범위 내의 대상들을 타겟팅한다.
2. 타겟팅된 모든 대상에게 다수의 참격이 발생한다.
3. 참격이 종료되면 각 대상에게 폭발 범위 피해가 발생한다.

타겟 수 제한, 참격 횟수, 폭발 반경은 미정이다.

### A06. 파이어 스톰 (Fire Storm)

- 분류: 자동
- 쿨타임: 중간
- 피해량: 중간
- 최초 공격 범위: 좁음
- 최종 밀치기 범위: 중간

**작동 방식**

1. 주변에 지속 피해를 가한다.
2. 해당 범위 내 적에게 슬로우를 적용한다.
3. 일정 시간 뒤 폭발한다.
4. 폭발하면서 주변 적을 밀쳐낸다.

지속시간, 슬로우 비율, 피해 간격은 미정이다.

## Claude 개발 시 유의 사항

- 본 문서의 정성적 수치를 임의의 확정 숫자로 변환하지 않는다.
- 아직 확정되지 않은 스킬 효과를 기본 사양으로 추가하지 않는다.
- 수동 역할군은 확정 전까지 임시 분류로 취급한다.
- 스킬 레벨과 캐릭터 레벨을 서로 구분한다.
- Lv.5·10·15는 **스킬 레벨 기준**이다.
- Lv.45·60은 **캐릭터 레벨 기준**이다.
- 궁극기는 적 처치로 충전하며 시간 경과 충전은 현재 확정된 규칙에 포함되지 않는다.
- 현재 게임 기획과 기존 슬레이어즈 세계관의 상세 전투 설정을 임의로 동일시하지 않는다.

## 현재 기획 상태

**확정 또는 잠정 결정된 요소**
- 게임 장르 및 기본 전투 구조
- 플레이어블 캐릭터 3명
- 캐릭터별 전투 특성
