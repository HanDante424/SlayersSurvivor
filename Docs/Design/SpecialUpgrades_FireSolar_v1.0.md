# 에른 스트레이 — 파이어 슬래시·솔라 슬래시 특수 강화 v1.0

작성 기준: 2026-11-09 (사용자 확정 기획서 요약 + 구현 메모). 강화 명칭은 임시.

## 원칙
- 스킬 Lv.5·10·15 에서 3개 중 1개 선택, 이전 단계 강화는 유지·중첩 (스킬당 최대 27조합)
- 일반 스탯 증가율은 합연산, 피해량은 타격마다 내림, 쿨타임 감소 상한 90%
- 대량 참격·처치 연쇄는 의도된 설계. **조건 없는 자기 재생성·같은 적 사망 중복 처리·종료 누락 무한 반복만 금지**
- 기획서에 없는 수치는 임의로 확정하지 않음 → `SkillTuning.asset` 의 `[임시]` 항목

## 파이어 슬래시 (기본: 자동 · 피해 10 · 바라보는 방향)
| Lv | 강화 | 효과 |
|---|---|---|
| 5 | 대상 추적 | 가장 가까운 적 방향 공격 |
| 5 | 난사 | 무작위 방향 3회 |
| 5 | 양방향 공격 | 정방향 + 역방향 |
| 10 | 검기 발사 | 참격 후 같은 위력의 검기를 공격 방향으로 |
| 10 | 연속 공격 생성 | 참격 위치에서 120° 간격 3방향 추가 참격 (1 + 3) |
| 10 | 빠른 공격 | 일반 감소 후 남은 쿨타임 ×0.5, 최종 10% 미만 불가 |
| 15 | 삼연발 | 공격 방향 좌우 60° 추가 2회 |
| 15 | 묵직한 일격 | 범위 +50% · 공격력 +100% · 최종 쿨타임 감소율(빠른 공격 포함) 1%당 공격력 +2%, 실제 쿨타임은 기본값 |
| 15 | 죽음의 메아리 | 적 사망 위치에서 120° 3방향 참격, 처치 연쇄 허용 |

예: 일반 감소 50% + 빠른 공격 → 75% → 묵직한 일격 +150% + 100% = +250% → 피해 35.

## 솔라 슬래시 (기본: 자동 · 베기 5 → 후속 폭발 12 + 넉백)
| Lv | 강화 | 효과 |
|---|---|---|
| 5 | 충격 발산 | 넉백 범위 +100% |
| 5 | 뇌진탕 | 후속타로 넉백된 적이 다른 적과 충돌 시 1초 기절 |
| 5 | 느린 회복 | 피해 시 2초간 이동속도 50% 감소 |
| 10 | 메아리 | 완전 종료 후 1회 재발동 (재발동은 메아리 없음) · 쿨타임 +25% |
| 10 | 타오름 | 후속타 삭제 → 5초 지속, 매초 총 피해(17), 범위 +50%, 종료 후 쿨타임. 넉백 유지·실제 넉백 범위는 기본값. 누적 넉백 범위 5%당 범위 +5% · 피해 +1% |
| 10 | 흑점 폭발 | 후속타 즉시 · 넉백 범위 +50% |
| 15 | 연속 폭발 | 후속타 +2회 (총 3회) |
| 15 | 초신성 | 넉백 범위 +50% · 누적 넉백 범위 1%당 피해 +1% · 쿨타임 +50% |
| 15 | 플레어 | 총 피해 +50% · 피해 시 2초 50% 둔화 · 쿨타임 -25% |

상호작용
- 뇌진탕 → 타오름: 선택 가능, 경고 확인창(그래도 선택 / 취소). 뇌진탕은 기록만 남고 비활성
- 타오름 → 연속 폭발: 선택 불가 (회색 + 이유). 데이터상 같이 있어도 발동 안 함
- 메아리 + 연속 폭발: 베기 2 + 후속 폭발 6 = 기본 82
- 충격 발산 + 타오름 + 초신성: 누적 넉백 +150% → 범위 +200%, 피해 +30% + 150% = +180% → 틱당 47 (5틱 235)

## 구현 메모
- 공통: `Skill.SpecialOptions(lv)` (id · locked · warning), `HasSpecial(id)`, `SpecialDamageBonus / SpecialRangeBonus / SpecialCooldownReduction / SpecialCooldownIncrease` 훅,
  `CooldownMultiplier` override(계산 순서가 정해진 강화), `AutoSkill.CastDuration`(지속형 → 종료 후 쿨타임), `Enemy.Killed`(적마다 1회) — 다른 캐릭터 스킬도 재사용
- 파이어 슬래시 생성 단계: Lv.5 방향 → 삼연발 ×3 → 참격마다 Lv.10 추가 공격 1회. 추가 참격은 다시 추가 공격을 만들지 않음 (난사 + 연속 + 삼연발 = 36)
- 죽음의 메아리: `Enemy.Die` 는 적마다 한 번 → 메아리 1회. 다음 프레임 이후(`fireEchoDelay`) 생성해 한 프레임 재귀를 막음
- 쿨타임 일반식: 기본 × max(0.1, 1 − min(감소 합, 0.9) + 증가 합). 감소(기본 강화·플레어)와 증가(메아리·초신성)를 합연산

### 구현 시 해석한 항목 (확인 필요)
1. **넉백 범위** = 후속 폭발이 적을 밀어내는 원. 기본은 폭발 피해 원과 같고, 넉백 범위 증가는 이 원만 키움 → 피해 원 밖 ~ 넉백 범위 안의 적은 피해 없이 밀려남 (F1 하늘색 원). 기본 강화 "범위"도 넉백 범위에 합연산
2. 쿨타임 증가·감소가 함께 있을 때 합연산 (예: 기본 강화 -50% + 초신성 +50% = 기본 쿨타임)
3. 죽음의 메아리 참격 = 기본 참격 3개 (Lv.5 방향·Lv.10 추가 공격·삼연발 미적용). 3방향 기준 각도는 무작위. 어떤 스킬로 죽은 적이든 발동
4. 연속 폭발 간격 = 기본 베기→폭발 간격 × 비율 (흑점 폭발로 첫 폭발이 즉시여도 간격은 기본값)
5. ~~메아리·연속 폭발은 쿨타임이 발동 시점부터 돎~~ → **확정**: 메아리·연속 폭발이 있으면 베기 → 폭발(+연속) → 메아리 → 폭발(+연속)이 모두 끝난 뒤 쿨타임 시작. 기본 솔라 슬래시도 베기 → 폭발이 끝난 뒤부터 (타오름은 5초 지속 공격 종료 후)
6. 타오름 틱: 0·1·2·3·4초에 5회, 넉백은 매 틱 (`solarBurnKnockEveryTick`), 뇌진탕 기절 대상은 넉백된 적만 (`concussionStunsOther`)
7. 검기: 관통, 적마다 1회 피해
