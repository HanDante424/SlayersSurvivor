# 레이드 보스 카구츠치 — 구현 계획 v0.1 (2026-11-13, origin/main a18de8a 기준)

설정 원문: [Raid_Kagutsuchi_Setting_v0.1.md](Raid_Kagutsuchi_Setting_v0.1.md).
이 문서는 **구조 조사 + 구현 순서 제안**까지만 다룹니다. 체력 · 피해 · 쿨타임 · 페이즈 기준 · 패턴은 **정하지 않았습니다**.
가니악 레이드는 그대로 두고, 카구츠치는 별도 보스로 추가하는 것을 전제로 합니다.

## 1. 기존 레이드 시스템 조사 (요청 1 · 2)

### 1-1. 그대로 재사용 가능 (보스 무관)
| 기능 | 위치 | 카구츠치에서 |
|---|---|---|
| 레이드 스테이지 · 맵 경계 · 경계 표시 | `Core/Stage.cs` | 그대로. 맵 크기는 지금 상수 1개 (`RaidHalfSize` 36 × 24) → 보스별 맵 크기가 필요하면 값으로 분리 |
| 보스 처치 = 승리 | `RaidBoss.cs` `RaidStage.OnKilled` → `GameManager.StageCleared` | 그대로 (승리 문구 "레이드 성공!" — 사망 연출은 넣지 않음, 7-1 제약) |
| 보스 체력 바 | `GameManager.DrawBossBar` | 그대로 (페이즈 경계 눈금은 추가 필요) |
| 공격 경고 표시 | `BossWarning` (원 · 반원 · 직사각형, 위치 · 크기 변경) | 그대로. 색은 붉은색 고정 → 화염 테마에 맞추려면 색 지정 추가 |
| 맵 가르는 레이저 · 판정 | `RaidLaser` (`Ganiac.cs` 안) | **직선 화염 방출**에 재사용 가능. 지금 색이 검정 · 보라 고정 → 색을 인자로 |
| 장판 (안에 있으면 효과) | `IceZone` (`MidBoss.cs`, 플레이어 감속) | **화염 구역**의 틀로 사용 가능. 지금은 감속만 → 지속 피해 추가 필요 |
| 카메라 맵 전체 축소 · 흔들림 | `CameraFollow.ZoomToFullMap / ResetZoom / Shake` | 그대로 |
| 보스 → 플레이어 피해 | `Player.TakeDamage(피해, 피격 무적 무시)` · `Player.HitByBoss(피해, 기절, 밀림 방향, 거리)` · `ApplyZoneSlow` | 그대로 |
| 보스 공통 성질 | `Enemy.IsBoss` (넉백 · 밀림 없음, 소각 보스 비율) | `IsBoss` 에 카구츠치 추가 |
| 치트 | 보스 체력 절반 (F11) · -30% | 그대로 (`AnyBoss` 가 레이드 보스를 찾음) |

### 1-2. 가니악에 묶여 있어서 바꿔야 하는 곳 (복수 레이드 보스 불가 원인)
**현재는 레이드 보스를 여러 개 등록 · 선택할 수 없습니다.** 레이드 = 가니악으로 고정된 곳:

| # | 위치 | 지금 | 바꿀 방향 |
|---|---|---|---|
| 1 | `RaidBoss.cs:31` `RaidStage.Begin` | `Enemy.Spawn(EnemyKind.Ganiac, …)` 고정 | `RaidStage.Selected` (선택한 보스 종류) 로 생성 |
| 2 | 타이틀 → 캐릭터 선택 | "레이드 보스" 하나 | **레이드 보스 선택 화면** (가니악 / 카구츠치) → 캐릭터 선택 |
| 3 | `GameManager.cs:672` 체력 바 숨김 | `GaniacAI.InIntro` 직접 확인 | 보스 AI 공통 인터페이스 (`IRaidBossAI.HideBossBar`) |
| 4 | `GameManager.cs:708` HUD | `GaniacAI.DrawHud` 직접 호출 | 공통 인터페이스 `DrawHud` (보스별) |
| 5 | `Enemy.Setup` · `EnemyBehaviors.Behave` | 보스마다 `case` · 필드 하나씩 (`ganiacAI`) | 카구츠치 `case` 추가 (기존 중간보스와 같은 방식) — 또는 공통 AI 필드 하나로 정리 |
| 6 | `DebugCheats` 특수 패턴 ON/OFF | `NoGaniacSpecial` 4칸 · 이름 고정 | 보스별 목록 (지금 레이드 보스의 특수 패턴 이름을 AI 가 제공) |

### 1-3. 패턴 스케줄러 (요청 3 · 5)
- 지금 패턴 규칙 (한 번에 하나 · 끝난 뒤 쿨타임 · 조건 맞는 것 중 무작위 · 공통 쿨타임 · 기절 시 일시 정지 · 경고 정리) 은 **`GaniacAI` 안에 직접** 들어 있음. 중간보스 2종도 각자 복사본을 가짐
- 공용 도우미 (`Wait` · `WaitActive` · `Move` · `Track` · `PlayerInCircle` · `PlayerInHalf` · `InBox` · `ExitDistance`) 도 `GaniacAI` 안
- **제안**: 공통 부분을 **`RaidBossAI` 기반 클래스**로 뽑고, 가니악 · 카구츠치가 각각 상속
  - 기반: 패턴 표 (쿨타임 · 첫 사용 · 조건 · 해제 여부) · 스케줄러 · 공통 쿨타임 · 체력 문턱 트리거 · 페이즈 · 대기 · 이동 · 경고 정리 · 판정 도우미
  - 보스별: 패턴 내용 · 수치 상수 · 등장 연출 · HUD
  - 가니악은 **동작을 바꾸지 않고** 옮기기만 함 (옮긴 뒤 가니악 패턴을 한 번 플레이 확인). 부담되면 가니악은 그대로 두고 카구츠치만 새 기반으로 시작하는 것도 가능

### 1-4. 페이즈 (요청 5)
- 가니악은 "체력 50% 아래 강화" 불(bool) 하나 + 체력 문턱 특수 패턴 (90 · 60 · 30 / 75 · 50 · 25%) 구조. **페이즈 전환 처리 (전환 연출 · 패턴 표 교체 · 진행 중 패턴 정리) 는 없음**
- 카구츠치용 제안: 기반 클래스에 페이즈 목록 (체력 비율 → 그 페이즈의 패턴 표) + 전환 순간 처리 (진행 중 패턴이 끝난 뒤 전환 · 전환 연출 자리 · 체력 바 눈금). **비율 · 연출은 미정 → 빈 값**
- 2페이즈를 "본래 인격이 깨어나는 단계" 로 처리하지 않음 (설정 5-3)

## 2. 카구츠치 전투 요소 구현 가능성 (요청 4 · 7)

| 요소 (설정) | 지금 있는 것 | 추가 필요 | 비고 |
|---|---|---|---|
| 검격 (전방 · 화염 동반) | 가니악 횡베기 · 전방위 · 돌진 (반원 · 원 · 직사각형 판정) | 화염 연출 (색 · 이펙트) | 아메노무라쿠모 = **강력한 검**으로만 (시간 · 현실 조작 등 권능 없음, 설정 3-2 · 7-3) |
| 지정 위치 화염 분출 | 장로 낙뢰 (경고 → 지연 판정), 레니아 낙하 지점 표시 | 화염 분출 이펙트 | 바로 구현 가능 |
| 직선 화염 방출 | `RaidLaser` | 색 인자 · 화염 이펙트 | 바로 구현 가능 |
| 지면 화염 구역 · 경로 제한 | `IceZone` (감속 장판) | **플레이어 지속 피해** (장판 안 틱 피해) | 지속 시간 · 틱 간격 · 피해 미정 |
| 화염 확산 | — | 구역이 번지는 규칙 (시간 · 거리) | 규칙 미정 |
| **야타의 거울 (방어)** | 홉 고블린 기사 방패 막기 (`Enemy.Hit` 의 `knightAI.DamageMul` — 정면 180도 피해 -80%) | `Enemy.Hit` 공통 **보스 피해 배율 훅** (기사 하드코딩 일반화) | 무효 / 감소 비율 · 방향 · 지속 시간 미정. **흡수한 공격을 반사 · 재발사하지 않음** (설정 3-3). "흡수 · 보관" 은 연출 (빨려 들어가는 표시) 까지만 |
| 화염 상태이상 (플레이어) | 없음. 플레이어는 받는 피해가 숫자 하나 · 상태이상은 기절 · 감속뿐 | 플레이어 **화상** (지속 피해) 상태 | 화염의 지속 피해 여부 미정 (설정 8) |
| 악신 침식 | — | — | 특정 악신 권능 사용 · 전투 중 인격 교체 **추가하지 않음** (설정 3-4). 아마테라스 권능 기반 공격도 미설계 (3-5) |

### 피해 · 상태이상 호환성
- **플레이어 → 카구츠치**: 지금 피해 계산 (`DamageInfo` · 직접 / 지속 / 특수 / 고정) 그대로 호환
- **카구츠치가 받는 상태이상**: 지금 보스도 **기절 · 슬로우에 걸림** (가니악 포함). 기절 · 넉백 · 감속 저항 = 미정 (설정 8)
- **에른 스트레이의 화염 (화상 · 옥염 등)**: 화염 보스라 "화염 저항" 을 둘지 결정 필요 (지금 그런 구분 없음)
- **카구츠치 → 플레이어**: 피해는 숫자만, 0.35초 피격 무적. 화상 같은 지속 피해를 넣으려면 플레이어 쪽 새 상태 필요

## 4. 구현 순서 (제안)

### 1단계 — 레이드 보스 복수 등록 (수치 · 패턴 불필요)
1. `RaidBossRoster` (보스 목록: 이름 · 종류 · 맵 크기 · 설명) + `RaidStage.Selected`
2. 타이틀 "레이드 보스" → **레이드 보스 선택 화면** → 캐릭터 선택. 가니악 동작은 그대로
3. `GameManager` · `DebugCheats` 의 가니악 직접 참조 (1-2 표 3 · 4 · 6) 를 공통 인터페이스로
4. `EnemyKind.Kagutsuchi` + 빈 `KagutsuchiAI` (도형 · 추격만, 수치 전부 [임시]) — 레이드 선택에 "카구츠치 (준비 중)" 로 표시

### 2단계 — 공통 기반
5. `RaidBossAI` 기반 클래스 (스케줄러 · 페이즈 · 도우미) — 카구츠치부터 사용, 가니악 이전은 선택
6. `Enemy.Hit` 보스 피해 배율 훅 (거울용, 기사 방패도 이쪽으로)
7. `BossWarning` · `RaidLaser` 색 지정
8. 화염 구역 (`IceZone` 일반화: 감속 + 틱 피해) · 플레이어 화상 상태 (결정 후)

### 3단계 — 패턴 (사용자 확정 후)
9. 1페이즈 · 2페이즈 패턴 (설정 5-2 · 5-3 후보 중 사용자가 정한 것)
10. 페이즈 전환 · 등장 연출 · 치트 (패턴 ON/OFF · 페이즈 건너뛰기)

### 4단계 — 리소스
11. 본체 · 거울 · 화염 이펙트 받아서 교체 (`sprite-intake`)
