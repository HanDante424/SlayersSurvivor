규칙: [Sprite_Rules_v0.1.md](Sprite_Rules_v0.1.md) 3장 (왼쪽을 보는 3/4 측면 한 벌 + 좌우 반전, 포즈 = 한 장, 달리기만 한 줄 시트, 발끝 기준).
근거: 스킬 목록 `SkillList_Current_2026-11-13.md`, 공격 모션 호출부 (`PlayAttack`: 에른 `ErnActiveSkills` · `ErnAutoSkills` · `TripleSlash`, 레니아 `LeniaSkills` · `LeniaManualSkills`).
`[임시]` = 값 미확정, `[해석]` = 제가 정한 해석 (사용자 확인 필요).

## 0-1. 결정 (2026-11-18 사용자): **공격 모션은 수동 스킬 사용 때만**
- 자동 스킬 (에른 A01 파이어 슬래시 · A02 솔라 슬래시 (메아리 재발동 포함), 레니아 LA01 · LA02 투척 · LA03 ~ LA05 터렛 설치) 은 모션 없이 이펙트 · 투사체만. 이때 대상 쪽으로 돌아보던 동작도 같이 없어짐.
- 모션이 나오는 것: 에른 수동 M01 트리플 슬래시 · M03 오버 드라이브 · M04 파이어 브레이커 · M05 파이어 엑스큐션, 레니아 수동 LM01 ~ LM04. (D01 · M02 돌진 · 파이어 스톰 · 궁극기는 원래 모션 호출 없음)
- 아래 포즈 대응표에서 **자동 스킬 (A01 · A02 · A03 ~ A06 · LA01 ~ LA05) 은 공격 포즈가 필요 없음** → 에른 `Atk_Slash` 는 M01 · M05, `Atk_Spin` 은 U01 이 아닌 수동에서만 필요한지 재검토, 레니아 `Atk_Throw` · `Atk_Deploy` 는 **불필요** (수동 `Atk_Smash` · `Atk_Command` 만 해당).

## 0. 현재 상태 (코드로 확인)
- 지금은 모든 스킬이 **공격 모션 1종** (`{id}_Slash`, 4방향 × 8프레임) 을 `Player.PlayAttack()` 으로 재생. 스킬별 별도 동작 없음.
  - 에른: 대각 내려베기 한 종류로 자동 · 수동 · 돌진 전부 (돌진 · 파이어 스톰 등은 연출이 이펙트 쪽).
  - 레니아: 스패너 휘두르기 한 종류로 투척 · 터렛 설치 · 수동 4종 전부.
- 에른 `ErnStray_Stand` 는 적용 완료 (정지). 달리기 · 공격은 기존 4방향 시트.

## 3. 제작 규칙 (GPT 요청 시 공통)
- 왼쪽을 보는 3/4 측면, 같은 캐릭터 · 같은 의상 · 같은 비율 (`ErnStray_Stand` 를 기준 그림으로 함께 제공)
- **배경 완전 투명**, 가장자리 흰 띠 없이
- 발 (또는 몸 맨 아래) 이 그림 아래쪽에서 가깝게 (여백 ~20px). 점프형 동작 (공중 프레임) 은 예외
- 칸 · 캔버스 크기는 포즈마다 달라도 됨 (무기 · 이펙트가 잘리지 않게 여유). 달리기 시트만 정사각 칸 8프레임 한 줄
- 몸 크기는 `Stand` 와 같은 배율 (포즈마다 커졌다 작아지지 않게. 필요하면 코드 `PoseSizes` 로 보정)
- 검 · 도구 · 이펙트는 몸과 겹쳐도 되지만 **캐릭터 그림에 화염 · 번개 이펙트를 그려 넣지 않기** (이펙트는 별도 스프라이트가 담당)
- 저장: `Art/Incoming/{id}/` → 검사 (sprite-intake) → `Assets/Resources/Sprites/`

## 4. 코드 쪽 필요 작업 (그림이 오면)
1. **포즈 재생**: 지금 `PlayAttack` 은 시트 클립 1개 재생. 포즈 방식은 `HoldPose(키, 방향, 시간)` 으로 준비 → 타격 순서를 짧게 이어 보여 줌 (예: SlashReady 0.1초 → Slash 0.2초 → 대기). 지속 시간 `[임시]`.
2. **스킬 → 포즈 매핑 표** (스킬이 포즈 이름을 고르게): 기본값 = `Slash`. 그림이 없는 포즈는 기존 4방향 `{id}_Slash` 로 대체.
3. **크기 · 위치 표**: `PoseSizes` · `PoseDrops` 같은 코드 표 (카구츠치 2페이즈 방식), 포즈마다 발끝 기준 자동 정렬.
4. **스킬 이펙트 위치**: `fxOffset` · 이펙트 시작 위치가 기존 몸 기준 → 새 포즈에서 검 끝 위치가 다르므로 Play 로 보며 조정.
5. 캐릭터 선택 카드는 `Stand` 사용으로 변경.

## 5. 제작 순서 제안 `[해석]`
1. 에른: `Run` → `Atk_Slash` (+ `SlashReady`) 먼저. 이 둘이면 가장 자주 보이는 모습 (이동 · 기본 공격) 이 새 그림이 됨.
2. 에른 `Atk_Smash` → 확장 세트.
3. 레니아는 에른이 끝난 뒤 같은 순서.
