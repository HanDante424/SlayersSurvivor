# 카구츠치 2페이즈 스펙 v0.1 (2026-11-14, 기획만 · 미구현)

표기: **(사용자)** = 사용자가 정한 값 · **[임시]** = 기획에 없어 임시로 정한 값 (확정 대기).

## 1. 컨셉 (사용자)
매우 빠른 속도의 연격 + 강한 물리력 (스턴 · 넉백 · 지진).
1페이즈(고정형, 레이저 · 검 · 화염장벽, 경고 김)와 달리 **이동형 근접 연격**, 경고 짧고 템포 빠름.
평소에는 제자리 대기, **이동은 이동 패턴으로만** (경로 워닝 표시).

## 2. 1페이즈 → 2페이즈 진입 연출 (사용자)
카구츠치는 연출 끝까지 **무적**, 이 동안 패턴 없음. 이 연출이 기존 페이즈 전환 연출 자리를 **대체** [해석].

| 시간 | 내용 |
|---|---|
| 0초 | 카메라가 카구츠치로 확대, 카구츠치가 고개를 숙임 |
| 0~2초 | 스프라이트 + 카메라가 함께 흔들림 (스프라이트가 더 흔들려 보임), 카구츠치에서 화상 파티클, 카메라는 매우 천천히 추가 확대 |
| 2초 | 화면 흰색 점멸 시작 (0.5초 유지 후 천천히 사라짐), 동시에 카구츠치 맵 이탈, 카메라 맵 전체로 축소 |

[임시] 처음 확대 0.5초 · 시야 4.5 → 4.0 · 고개 숙임 = 그림 교체 (`Intro1` → `Intro2`, 연출 시작 0.5초 뒤) · 화상 파티클은 몸 주변에서 위로 피어오름.

## 3. 2페이즈 입장 (사용자)
1. **3초**간 맵 중앙에 **반경 16**까지 점점 커지는 워닝 사인
2. 끝나면 화면 **0.2초** 점멸, 워닝 중앙에 카구츠치가 **지면강타**로 등장 (`Kagutsuchi_P2_Atk_GroundSmashHeavy`)
3. 워닝 끝나는 순간: 반경 16 안 플레이어에게 피해 (**40** [임시]) + **반경과 상관없이 플레이어를 맵 끝으로 넉백**
4. 등장과 동시에 카메라가 카구츠치 쪽으로 축소 [해석] · 카구츠치 체력 **최대치로 회복 연출 1초** · 화면 흔들림 **1초** (여진, 강하게 시작해 선형으로 약해짐 [임시])
5. 이후 카메라 기본 사양(맵 전체)으로 초기화, **무적 해제**, 패턴 시작

[임시] 넉백: 중심에서 바깥 방향 (정확히 중심이면 무작위) · 맵 경계까지 · 0.3초 · 이동 불가 0.3초 · 기절 없음. 구현은 `Player.HitByBoss` 활용 가능 (맵 경계 처리 확인 필요).

## 4. 공통 규칙
- 패턴: 한 번에 하나 · 쿨타임은 끝난 뒤부터 · 조건 맞는 준비된 패턴 중 무작위 · 기절하면 멈췄다가 이어서 (1페이즈 방식)
- 패턴 간 공통 쿨타임 **0.5초** [임시]
- **기절 연계 가능** (재기절 방지 없음, 사용자) → 연속 기절 체감은 테스트 후 조정
- 찍기 · 어퍼컷 · 내려찍기마다 **지진 화면 흔들림** (균열 장판 없음, 사용자)
- 피해량은 전부 [임시]. 피격 무적 0.35초 적용
- 1페이즈의 야타의 거울 · 아메노무라쿠모 · 1페이즈 특수 패턴은 2페이즈에서 사용 안 함 [임시]
