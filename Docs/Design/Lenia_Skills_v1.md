## 구현 메모
- 캐릭터별 스킬 목록: `CharacterInfo.catalog` · `startSkill` (에른 = A01 파이어 슬래시, 레니아 = LA01 스패너 투척). 레니아는 캐릭터 선택에서 **플레이 가능**
- 터렛: `Turret` — 사거리 안 가장 가까운 적 쪽으로 방향(4방향 시트)을 바꾸고 공격 쿨타임마다 발사. 대상이 없으면 쿨타임을 소모하지 않음. 지속시간이 끝나면 사라짐
  - 표준: 반동 시트 재생 + 탄환 직진 / 미사일: 정지 시트 + 발사 순간 눌림 연출(코드) + 유도 미사일 · 추진 연기 3종 무작위 · 폭발 / 테슬라: 링 하강 시트, 3번째 프레임에 방전 · 번개 줄기(띠 4종 무작위, 길이에 맞춰 반복) · 적중 스파크 · 감전 표시
- 피해 구분: 터렛 공격 = 설치(직접 사용)의 **간접 사용** (같은 사용 번호), 포격 = 첫 발 직접 · 나머지 간접
- 터렛 강화 · 과부화: 연출만 (수치 강화 없음). 강화 = 스패너 조이기 1.5초 + **강화된 동안 터렛 우측 상단에서 기어 회전** (`Lenia_Gear`). 과부화 = 망치 내려치기 + 스파크

## [해석] 원문에 없어 구현에서 정한 것
- 터렛 소환: 플레이어 주변 터렛 사거리 안에 적이 있을 때만 설치 (없으면 대기, 쿨타임 소모 없음). 설치 위치 = 플레이어 발밑 근처 무작위
- 테슬라 3회 도탄 = 첫 대상 + 3명 (최대 4명), 같은 적 중복 없음
- 지면 강타: 피해량이 없어 **기절만** (피해 0), 약한 밀치기. 기절 범위 = **플레이어 중심 원** ("주변"), 망치는 앞쪽에 내려침 (연출)
- 기본 강화 '범위': 투척물 크기 · 터렛 사거리 · 미사일 폭발 반경 · 도탄 거리 · 포격 반경에 적용 (터렛은 설치 시점 값). '쿨타임': 설치 쿨타임에만 (터렛 공격 쿨타임은 고정)
- 투척 · 총알은 손 · 포신 위치에서 조준
- 테슬라 기절은 도탄 대상에게도 적용, 터렛 강화 · 과부화는 터렛이 없어도 사용 가능(쿨타임 소모)
- 포격 위치: 플레이어 주변 반경 안 무작위

### [해석] 원문만으로 정해지지 않아 구현에서 정한 것
- 공구 벨트 기본 강화 '모든 투사체 사거리' = 투척 사거리 + **터렛 사거리** (2026-11-12 사용자 확인). 터렛에서는 자동화 공정 '사거리' %와 합연산, 설치 시점 값
- 공구 벨트 기본 강화 '모든 쿨타임 감소' = 레니아의 **모든 스킬** 쿨타임 (투척만이 아님)
- 과잉 장전: 스패너 · 망치 '직접 사용'을 함께 셈. 3회째 다음 사용이 +5, 그 강화된 사용은 다음 3회에 포함하지 않음
- 표적 지시: 다시 걸면 지속 시간 5초로 **갱신**, 효과는 중첩 없음 (계수형 곱 · 시간 합 규칙을 적용하면 스패너 연타로 무한히 커지므로). 표적 표시 그림은 없음
- 재활용: 투척이 진행 중(추가 투사체 발사 중)에는 쿨타임이 아직 시작 전이라 감소 없음 (다른 남은 쿨타임 감소와 같은 규칙)
- 자동화 공정 기본 강화 "'터렛' 스킬 '쿨타임' +2.5%" = 오타로 보고 **쿨타임 감소** +2.5% 로 구현
- 장기 가동 "'설치' 스킬 '쿨타임 감소' -50%" = 쿨타임 ×1.5 (스패너 초대형 "'쿨타임 감소' -25%" = ×1.25 와 같은 방식)
- 요새화: 지속된 시간은 **초 단위 내림** (1.9초 = +10%)
- 신속 가동 '공격 간격' -15% 는 소환 후 3초 동안만
- '기절' 스킬 = 망치 투척 · 테슬라 터렛 · 지면 강타 + 기절 특수 강화를 얻은 스패너 투척(머리 가격) · 미사일 터렛(철갑탄) · 포격 실시(철갑탄)
- 범위 충격: '직접 사용' 기절 = 스킬 본체에서 나온 기절. 터렛 공격 · 추가 투사체 · 충격파 · 범위 충격 자신의 기절은 간접 → 퍼지지 않음
- 부서진 두개골: '기절 지속 시간' = 이번 기절의 **총** 지속 시간 (남은 시간 아님, 기절이 이어서 걸리면 누적)
- 충격 잔향: 충격파 반경 **2** [임시] (원문에 없음). 받은 피해 5%가 1 미만이면 발생하지 않음. 기절 중 죽은 적은 발생 없음
- 충격 역학 '기절' '지속 시간'은 모든 기절에 적용 (범위 충격 0.5초 포함)
