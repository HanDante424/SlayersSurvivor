# 어퍼컷 앞뒤 풍압 v2 — 상하 동일 너비

사용자 요청으로 위쪽을 아래쪽 너비에 맞춰 넓혀 삼각형 대신 원기둥형 소용돌이로 보정. 지피티 내장 이미지 편집 사용.
후방은 가득 찬 폭풍, 전방은 성긴 바람 파편·입자 유지. 상승→폭발→잔풍6단계.
원본6열2행에서 후방/전방을 분리해 각각3072×768(셀512×768, 6열1행)로 정리. 공통 배율과 지면 기준(256,652), 같은 프레임 인덱스 동시 재생.
engine clear_haze 후 원본 셀 분리/동일배율/지면 배치만 수행. 후방floor64, 전방floor16, edge2. 원본 source.png 및 실제 prompts.json 보존.
6개 서로 다른 비어 있지 않은 RGBA 프레임·규격·앞뒤 정렬 및 보스 합성 확인. 비교PNG/GIF는 검수용, 실제 게임 배치가 아님.
12fps 미리보기는 임시. 인게임 배율·위치·재생시간·실제 정렬 레이어값 미확정. 인게임 미연결, Unity 임포트/Play Mode 미검증.
기존 v1/v2 원화/코드/씬 삭제·수정 없음. 신규 앞뒤 PNG·제작산출물 및 자산 목록 문서만 추가/수정.
