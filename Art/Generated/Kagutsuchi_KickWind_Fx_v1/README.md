# 발차기 풍압 애니메이션

사용자 요청에 따라 built-in image_gen으로 발차기 전방에 퍼지는 백색·회백색 압축 공기/속도 잔상6프레임 제작. 압축→확장→최대 전방 충격파→가늘어짐→소멸의 단발 표시. 불꽃·캐릭터·발 그림은 포함하지 않음.

- 게임 리소스: Assets/Resources/Sprites/Kagutsuchi_P2_Fx_KickWind.png
- 1536×1024 RGBA, 512×512 셀3열×2행. 왼쪽→오른쪽, 위→아래 순서.
- 기본 오른쪽 발사. 반대쪽은 인게임 회전 또는 반전으로 사용 가능. 발사점 제안은 셀 (88,256)px, 정규 피벗(0.171875,0.5). 실제 발 접촉점·크기는 연결 시 검수 필요.
- 원본과 게임PNG/시트의 픽셀·알파 동일. frames/00..05.png, preview.gif, manifest.json, prompt.txt 함께 저장.
- GIF는 검수용 어두운 배경 합성, 프레임80ms×6=0.48초 + 빈 구간0.32초. 미리보기 전용이며 실제 발차기 타이밍/피해/판정을 정하지 않음.
- 검증: 6프레임 모두 서로 다른 이미지, RGBA/격자/alpha>16 경계가 셀 내부인지 확인. Unity Editor/Play Mode 미실행.
- 이번 작업은 리소스 제작만. runtimeConnected=false, 기존 코드/이미지/씬/설정/meta 변경·삭제 없음. 후속 연결 시 패턴 발차기 방향과 이동 경로·표시 수명을 맞추고 정상 종료/중단 정리 필요.
