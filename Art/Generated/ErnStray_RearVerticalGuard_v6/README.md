# 에른 후면 수직 검 자세 v6

사용자 최신 지시와 기존 공격 포즈를 참조하여 소매가 팔꿈치 굽힘과 전완 시작 부분까지 덮도록 연장. 화면 왼쪽 전완은 낮고 오른쪽 전완은 높도록 각도와 높이를 달리해 몸 앞 양손의 아래/위 검자루 그립을 표현. 손은 몸에 가리며 수직 검신·칼집 전경·기존 후면 자세 유지 지시. v5의 소매를 팔꿈치 위에 둔 해석은 최신 사용자 지시로 대체. 모델 재생성 차이는 비교 참고. 사용자 재검토 대기.

내장 image_gen으로 수정 생성. 로컬 후처리는 낮은 알파 정리, 투명 여백 추가, 비교 미리보기 제작만 수행. 전후 및 흰 배경 정적 검토, 투명 테두리/참조 해시 보존 검사 완료. 기존 v1~v5/Assets/.meta/코드 변경·삭제 없음. 사용자 채택 대기. Unity 임포트·컴파일·Play 미수행.
