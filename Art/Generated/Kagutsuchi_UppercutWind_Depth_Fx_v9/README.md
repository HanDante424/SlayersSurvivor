# 어퍼컷 풍압 v9 — 전방을 후방 바람결에 맞춤

사용자가 만족한 후방은 v8/v7과 픽셀 완전 일치.
지피티 내장 이미지 편집으로 전방의 굵은 파편을 섬세한 아이보리/은회색 바람결로 바꾸고 후방의 비대칭 나선 흐름에 맞춤. 많은 입자와 투명 틈 유지, 큰 덩어리는 짧은 조각으로 분리.
앞뒤 각각3072×768, 6열1행, 각512×768. 지면점(256,652), 같은 인덱스 동기 재생.
최초안·최종 원본/실제 prompts.json/개별 frames/시트/비교 GIF/manifest 포함. 기존 버전 보존.
후처리는3×2 셀 추출, engine clear_haze(floor16 edge2), 전체 동일배율과 측정 지면점 배치. 그림 수정은 이미지 도구로 수행.
검증: 양쪽6개의 서로 다른 비어 있지 않은 RGBA 프레임·규격·알파·여백 확인. 후방6프레임 v8 픽셀 일치. 보스 합성은 검수용이며 실제 게임 배치가 아님.
12fps는 임시 미리보기. 인게임 크기·위치·시간·정렬 레이어값 미확정. 인게임 미연결, Unity 임포트/Play Mode 미검증.
신규 PNG·제작산출물 및 자산목록 문서만 추가/수정. 기존 파일 삭제/코드·씬 변경·구조 변경 없음.
