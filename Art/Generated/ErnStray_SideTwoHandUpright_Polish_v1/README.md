# 에른 측면 양손 수직 검 — 별도 장면 보정본

사용자는 직전 생성 자세가 원래 의도와 달라도 다른 곳에 쓰겠다고 결정. 이 측면 직립·몸 앞 양손 수직 검 자세를 유지하여 손 그립/소매 연결·얼굴/헤어·복장/무기 디테일 보정. 기존 후면 수직 검 자세와 별도 작업본. 용도/스킬은 확정하지 않으며 원래 의도한 들어올리기 자세를 완성한 것으로 처리하지 않음.

내장 image_gen 수정 생성. 원 생성본 before.png 보존, 프롬프트/출처/검사 동봉. 로컬 처리는 낮은 알파 정리/여백/비교 이미지 제작만 수행. 정적 외형 검토와 투명 경계·참조 해시 보존 검사. 숨은 손가락의 실제 개수는 완전 검증 불가. 생성으로 인한 미세 차이는 비교 참고. 사용자 보정본 채택 대기. Assets/.meta/코드/Unity 연결 변경 없음, 컴파일·Play·임포트 미수행.
