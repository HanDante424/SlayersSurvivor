# 에른 후면 수직 검 자세 v5

이전 보정의 띠처럼 보이는 전완 문제가 남아 사용자 제공 Stand·복장·4면도 시트를 참조해 팔꿈치와 소매 구조 재생성. 소매는 팔꿈치 위에 두고 전완이 몸 앞쪽으로 굽어 들어가게 수정. 손은 몸 앞에 가림. 외곽 팔꿈치와 안쪽으로 올라가는 전완 흐름을 정적 시각 검토했으나 해부학적 정확성을 수치 검증한 것은 아니며 사용자 재검토 대기. 기존 자세 유지 지시, 재생성 미세 차이는 비교 참고.

내장 image_gen으로 수정 생성. 로컬 후처리는 낮은 알파 정리, 투명 여백 추가, 비교 미리보기 제작만 수행. 전후 및 흰 배경 정적 검토, 투명 테두리/참조 해시 보존 검사 완료. 기존 v1~v4/Assets/.meta/코드 변경·삭제 없음. 사용자 채택 대기. Unity 임포트·컴파일·Play 미수행.
