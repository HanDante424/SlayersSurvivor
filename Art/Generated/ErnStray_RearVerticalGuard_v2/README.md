# 에른 후면 수직 검 자세 v2

후면3/4 각도를 횡베기 참고와 맞추고, 다리 사이 간격을 약 두 배로 벌리는 방향으로 수정. 왼팔 상완7~8시/오른팔4~5시로 몸에서 떨어뜨려 준비 자세 강화. 손과 전완은 몸 앞에 숨김, 수직 검신은 몸 뒤 레이어, 빈 칼집은 등 위 전경 유지. 정확한 각도/간격 배율은 수치 검증하지 않았으며 정적 시각 검토 수행.

내장 image_gen 전체 재생성. 로컬 후처리는 낮은 알파 정리와 투명 캔버스 여백 추가, 비교 미리보기 제작만 수행. 프롬프트/출처/검사는 동봉 파일 참고. 사용자 채택 대기. 기존 v1/Assets/.meta/코드 보존. Unity 임포트·컴파일·Play 미수행. 스킬 대응/타이밍 미정.
