# 어퍼컷 풍압 v2 — 넓은 삼각형 하단

지피티 내장 이미지 편집 사용. v1을 참조해 하단 소용돌이를 넓혀 아래가 넓고 위가 좁은 삼각형/원뿔 형태로 보정. 상단 폭발과 6단계 순서 유지. 원본 v1 보존.
투명 시트3072×768, 6열1행, 셀512×768. 프레임/원본/실제 prompt/manifest/GIF 포함.
12fps 미리보기는 임시 검수용. 실제 인게임 크기·위치·재생시간·레이어 미확정, 인게임 미연결.
자동 추출의13개 위성 제거는 의도된 잔풍도 누락하므로 엔진 투영 경계를 이용해 원본 알파에서 수동 복원·공통 배율/지면 원점 배치. 자동 출력은 pipeline-comparison에 보존. 엔진 clear_haze(floor64 edge2)로 투명 잔여 안개 정리.
6개 서로 다른 비어 있지 않은 프레임·알파·시트 규격 확인. Unity 임포트/Play Mode 미검증.
코드·씬·기존 이미지 변경/삭제 없음. 신규 PNG·제작산출물, 자산 목록 문서만 추가/수정.
