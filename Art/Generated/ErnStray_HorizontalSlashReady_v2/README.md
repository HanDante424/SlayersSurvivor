# 에른 횡베기 준비 v2 — 2시 검각/마무리 보정 (2026-11-18)

사용자: v1 자세는 의도와 다르지만 만족스럽다고 선택함. 따라서 v1 자세를 보존하며 검끝을3시에서2시로 조금 올리고 마무리 보정. 원래 설명한 다른 팔 자세로 되돌리지 않음.
검 전체(폼멜-그립-가드-검신-검끝)를 그립 중심에서 화면 반시계 방향으로 올림. 첫 결과는 약2시25분의 완만한 각도로 보여 제외, 추가 각도 보정 결과 선택. 최종 검 방향은 정적 시각 검토상2시. 손등이 보이는 같은 오른손 그립, 빈 왼손, 낮은 자세/다리 배치와 디자인 유지 지시.
선/재질/투명 가장자리 마무리. 모델 재생성에 따른 미세한 얼굴·의상 세부 차이는 비교 이미지 검토 필요. 승인된 것은 기본 v1 자세이며 v2 파일의 최종 판단은 사용자에게 있음.

built-in image_gen으로 검/손목 각도와 그림 보정. 코드로 검이나 팔다리를 회전/붙이기하지 않음. 로컬 처리는 작은 분리 알파 잡점 정리, 모델의 전체 캔버스 해상도 변경을 균등 배율로 환산(원본 파트별 변형 없음), 1664×1152 투명 캔버스/발 하단90px 정렬, 비교·검사만.
