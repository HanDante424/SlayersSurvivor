# 어퍼컷 앞뒤 풍압 v4 — 파편 증가·후방 흐름 개선

사용자 요청으로 전방/후방 바람 파편과 입자를 조금 늘림. 특히 후방은 v3의 굵고 대칭적인 밧줄 형태를 줄이고 비대칭 나선 바람 띠와 주변 파편을 보강. 잘록한 허리, 위아래 폭, 투명한 내부 틈 유지.
지피티 내장 이미지 편집 사용. source.png/실제 prompt.txt/개별 frames/앞뒤 시트/비교 GIF/manifest 보존.
앞뒤 각각3072×768, 6열1행, 각512×768. 같은 프레임 인덱스로 동기 재생. 공통 지면점(256,652).
후처리는 원본6열2행을 셀 분리해 동일 배율과 지면점으로 재배치, engine clear_haze(뒤floor64, 앞floor16, edge2). 원본은 보존.

12fps는 임시 미리보기. 인게임 배율·위치·재생시간·정렬 레이어값 미확정. 인게임 미연결, Unity 임포트/Play Mode 미검증.
