# 어퍼컷 풍압 v7 — 후방 전면 재제작

기존 후방의 고리/폭발 모양을 수정하는 방식에서 벗어나 지피티 내장 이미지 생성으로 새 후방6프레임을 제작.
여러 겹의 얇은 바람결이 자연스럽게 올라가는 폭풍. 4번은 별도 폭발 장식 대신 상승 흐름 자체가 위로 풀려 터지는 모습.
전방6프레임은 v6와 픽셀 완전 일치, 변경 없음. 이전 버전 전체 보존.
앞뒤 각각3072×768, 6열1행, 각512×768. 지면 기준(256,652), 같은 인덱스 동기 재생.
원본·초기안·실제 prompts.json·개별 frames·시트·비교 GIF·manifest 포함.
후처리는 원본3×2 셀 추출, engine clear_haze(floor64 edge2), 동일배율1.7 및 측정 지면 띠 기준 배치. 원본 안개/잘림 수정은 이미지 도구에서 재생성했으며 초기안도 보존.
검증: 양쪽6개의 서로 다른 비어 있지 않은 RGBA프레임·규격·알파·후방 투명 여백 확인. 전방6프레임 v6 픽셀 일치. 보스 합성은 검수용이며 실제 게임 배치가 아님.
12fps는 임시 미리보기. 인게임 크기·위치·시간·정렬 레이어값 미확정. 인게임 미연결, Unity 임포트/Play Mode 미검증.
신규 PNG·제작산출물 및 자산목록 문서만 추가/수정. 기존 파일 삭제/코드·씬 변경·구조 변경 없음.
