# 어퍼컷 풍압 앞뒤 레이어 v1

상태: 제작본·연결 대기. 현재 v2의 느낌·6단계 흐름 보존.
후방 Back: v2를 픽셀 그대로 보존한 밀도 높은 삼각형 폭풍.
전방 Front: 지피티 내장 이미지 편집으로 제작한 성긴 바람 파편·입자. 중앙 몸체를 가리는 구름/폭풍 코어 없이 빈 공간 위주.
양쪽 시트3072×768, 6열1행, 각512×768, 좌→우 같은 프레임 인덱스로 동시 재생. 공통 지면 기준점(256,652). 레이어 순서 Back < Boss < Front.
전방 생성3×2의 각512셀은 원래 배율을 유지해 가로6열로 재배치하고 Y204 이동해 지면 원점을 맞춤. clear_haze(floor16 edge2)로 미세 안개 정리. 크롭/재배치만 수행, AI 원본 보존.
검증: 후방과 v2 픽셀 완전 일치, 양 레이어6프레임·규격·알파 확인, 전방 가시 픽셀이 모든 프레임에서 후방보다 적음. manifest에 픽셀 수·중앙 평균 알파 기록.

12fps 미리보기는 임시. 인게임 배율·위치·시간·실제 레이어값 미확정. Unity 임포트·Play Mode 미검증.
