# 카구츠치 1페이즈 후방 화염 루프

사용자 요청: 카구츠치와 옥좌 뒤에서 위협적으로 타올라 접근 위험을 시각적으로 전달하는 반복 화염 이펙트. Built-in image_gen으로 캐릭터/옥좌 없는 화염만 생성. 기존 화염 계열의 적색·주황·황금색 표현.

- 게임 PNG: Assets/Resources/Sprites/Kagutsuchi_P1_Fx_BackFire_Loop.png
- 1536×1024 RGBA, 384×512 셀 4열×2행, 총8프레임. 왼쪽→오른쪽/위→아래.
- 밑단 alpha>16 경계는 전 프레임 위에서472px로 동일. 지면 기준 피벗 제안 (0.5,40/512). 인게임 크기와 최종 표시 위치/레이어는 연결 시 검수 필요.
- 원본/게임 PNG/시트의 픽셀과 알파는 동일. 개별 frames/00..07.png와 반복 preview.gif 포함. 프레임8개 모두 서로 다른 이미지이며 셀 경계 잘림 없음(alpha>16 기준).
- GIF는 검수용 어두운 배경 합성, 프레임80ms(12.5fps)로 반복. 게임 PNG는 투명 배경 유지. 재생속도는 미리보기용이며 게임 수치로 확정하지 않음. 끝→처음의 실제 엔진 반복감 검수는 필요.
- runtimeConnected=false. 게임 코드·피해·접촉 판정·씬·설정·meta 변경 없음. PNG와 제작 산출물만 신규 추가, 기존 파일 삭제/덮어쓰기 없음.
- 정확한 생성 요청은 prompt.txt. Unity Editor/Play Mode 미실행. 추후 연결 시 카구츠치/옥좌 뒤에 배치하고 2페이즈 전환/사망/비활성화 때 표시 정리 필요.

## 인게임 연결 업데이트

현재 runtimeConnected=true. KagutsuchiBackFireFx로 본체/옥좌와 외곽선 뒤에 반복 표시. 임시12.5fps, 본체 Sprite 높이125%, 원화 밑단40px를 본체 하단에 맞춤. 입장 Scripted 해제부터1페이즈에 표시하며 숨김·전환·사망·AI비활성화에서 함께 정리. 피해/접촉 판정 추가 없음. 8프레임과 Root를 재사용하고 소유자가 해제. 독립 C# 컴파일 및 표시 수명 소스 검토 통과, Unity Play Mode 실제 크기/위치 검수는 남음. 최초 제작 설명의 runtimeConnected=false는 제작 당시 상태이며 이 업데이트로 대체.

## 등장 시점 변경

후속 사용자 결정으로 입장 Scripted 상태부터 후방 화염을 표시. 보스 자식 Transform에 귀속되어 화면 밖 등장과 걸어오는 동작부터 함께 이동. 이전 Scripted 해제 후 표시 설명은 이 변경으로 대체. 숨김·사망·2페이즈 전환 정리는 유지.
