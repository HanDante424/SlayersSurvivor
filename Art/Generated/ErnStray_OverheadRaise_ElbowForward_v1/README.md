# 에른 머리 위 검 들기 — 팔꿈치 전방 보정본

사용자 최신 요청: 양손으로 검을 머리 위로 번쩍 들고 팔꿈치를 바라보는 방향인 화면 왼쪽 앞으로 조금 굽히도록 보정. 양손/검자루는 머리 위, 검신12시 수직, 몸은 곧게 선 자세 유지. 첫 직선 팔 버전 before.png 보존. 앞서 다른 장면용으로 남긴 가슴 앞 양손 수직 검과 별도 작업본. 정확한 팔꿈치 각도나 관절 수치는 검증하지 않았으며 정적 비교 검토, 사용자 채택 대기.

내장 image_gen 수정 생성. 원 생성본 before.png 보존, 프롬프트/출처/검사 동봉. 로컬 처리는 낮은 알파 정리/여백/비교 이미지 제작만 수행. 정적 외형 검토와 투명 경계·참조 해시 보존 검사. 숨은 손가락의 실제 개수는 완전 검증 불가. 생성으로 인한 미세 차이는 비교 참고. 사용자 보정본 채택 대기. Assets/.meta/코드/Unity 연결 변경 없음, 컴파일·Play·임포트 미수행.
