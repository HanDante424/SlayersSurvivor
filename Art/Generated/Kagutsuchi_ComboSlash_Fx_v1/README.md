# 연속 횡베기 이펙트

Built-in image_gen으로 은백색 물리 반원 베기 6프레임 제작. 원본과 게임용 PNG는 동일한 RGBA 픽셀/알파. 1536×1024, 512×512 셀 3열×2행, 왼쪽→오른쪽/위→아래. 오른쪽 반원 방향이며 기준 피벗 (0.5,0.5). 반대편은 런타임 회전으로 사용 가능. 원화의 정확한 회전축·크기는 인게임 연결 시 검수 필요.

게임 리소스: Assets/Resources/Sprites/Kagutsuchi_Fx_ComboSlash.png
제작 산출물: generated-source.png, sprite-sheet-alpha.png, frames/00..05.png, preview.gif, manifest.json, prompt.txt.

검수 GIF만 기존 특수 패턴 2 연속 횡베기의 0.15초 표시/0.2초 간격을 참고. GIF 시간 양자화로 30/20ms 교대로 6프레임 150ms, 빈 화면 50ms. 최초 제작 시에는 런타임에 연결하지 않았으며 아래 업데이트에서 연결. 전투 데이터·씬·meta 수동 변경 없음. 새로운 피해량/범위/공격 시간 확정 없음.

검증: RGBA/격자/6프레임 alpha>32 경계가 셀 내부인지 확인. 생성 시트 육안 검토. Unity Editor/Play Mode 미실행. 후속 인게임 연결 시 현재 반원 판정 방향/반경/수명에 맞춰야 함.

## 인게임 연결 업데이트

KagutsuchiComboSlashFx가 1페이즈 특수 패턴 2 마지막 연속 횡베기에 연결됨. 기존 반원 반경12/표시0.15초/간격0.2초를 사용. 6프레임은 기존 표시 시간에 맞춰 한 번 재생. 판정 방향에 따라 원화를 회전하고 원화 반경194px로 크기 보정. AI가 표시 슬롯/스프라이트를 소유해 재사용·정리. 독립 C# 컴파일 통과, Unity Play Mode 표시 검수는 남음.

## 무작위 연속 베기 업데이트

본체 방향은 타격마다 독립 무작위 0~360도. 각 타격에 피해 없는 내부 베기 8개를 추가하고 본체 크기의 20~50%, 위치·각도·베기 진행 방향을 무작위화. 내부 베기는 본체 반원 밖을 KagutsuchiSlashClip으로 가림. 원본/시트/프레임 픽셀은 유지하며 런타임 표시를 재사용. 본체 피해 수치와 재생/공격 시간은 유지. 독립 C#/D3D 셰이더 문법 검사는 통과했고 Unity Play Mode 실제 검수는 남음.

## 원 전체 표시 업데이트

사용자 확정으로 현재 런타임은 본체·내부 8개 모두 원 전체 표시. 각 원은 기존 반원 시트를 동일 중심에서 180도 마주 놓은 두 렌더러로 구성. 원형 회전 각도·베기 진행 방향을 무작위 선택. 내부 배치·가림도 원 전체 기준. 본체 피해 판정은 반경12 원 전체이며 내부 8개는 피해 없음. 이전 문단의 반원 런타임 기준은 이 업데이트로 대체하며 PNG 자체는 기존 반원 시트 그대로 유지. 원본/미리보기 GIF는 원화 제작 당시의 반원 단위 프레임을 보여줌. 독립 C#/D3D 문법 검사는 통과했고 실제 Unity 이음새·피격 검수는 남음.
