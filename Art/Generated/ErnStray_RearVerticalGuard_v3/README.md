# 에른 후면 수직 검 자세 v3

사용자 파란색 표시 참고에 따라 양쪽 소매 끝부터 몸통 방향으로 이어지는 맨살 전완 추가. 전완 전체 비노출 지시는 최신 요청으로 대체하며 손/전완 말단만 몸 앞에 가림. 기존 후면3/4·넓은 다리·수직 검·등 칼집 구조 유지 지시. 모델 재생성에 따른 미세 차이는 비교 이미지 참고.

내장 image_gen으로 수정 생성. 로컬 후처리는 낮은 알파 정리, 투명 여백 추가, 비교 미리보기 제작만 수행. 전후 및 흰 배경 정적 검토, 투명 테두리/참조 해시 보존 검사 완료. 기존 v1/v2/Assets/.meta/코드 변경·삭제 없음. 사용자 채택 대기. Unity 임포트·컴파일·Play 미수행.
