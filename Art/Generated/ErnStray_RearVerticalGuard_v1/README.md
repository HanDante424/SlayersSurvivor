# 에른 후면 수직 검 자세 검토본

사용자 요청에 따른 단일 포즈. 등 정면, 왼쪽을 바라보는 옆얼굴, 곧은 두 다리와 뒤꿈치, 차분히 내려온 코트. 손·전완·검 하단은 몸 앞에 가려지고 상단 검신은 머리 뒤로 드러남. 빈 등 칼집이 가장 앞에 보임.

내장 image_gen으로 전체 그림 생성. 로컬 처리는 낮은 알파 정리 및 사방64px 투명 여백 추가만 수행. 프롬프트와 출처·검사 결과는 동봉 파일 참고. 단일 PNG에 시각적으로 겹침을 표현했으며 편집 가능한 분리 레이어 파일은 아님.

흰 배경으로 자세·가림·발 뒤꿈치 정적 검토. 가장자리 알파0 및 참조 해시 보존 검사 완료. 사용자 채택 대기. Assets, .meta, 코드 변경 없음. Unity 임포트·컴파일·Play·게임 내 크기는 미검증. 스킬 대응/타이밍은 정하지 않음.
