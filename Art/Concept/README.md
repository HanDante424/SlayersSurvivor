# 원화 (Concept Art)

게임에 직접 들어가지 않는 원본 그림을 보관하는 곳입니다.
`Assets` 밖에 있어서 Unity가 불러오지 않고, 빌드 용량에도 영향이 없습니다.
PNG, JPG, PSD 등은 Git LFS로 관리됩니다.

| 폴더 | 내용 |
|---|---|
| `Characters/` | 플레이어 캐릭터 |
| `Enemies/` | 적, 보스 |
| `Weapons/` | 무기, 투사체, 이펙트 |
| `Backgrounds/` | 배경, 바닥 타일, 맵 분위기 |
| `UI/` | 타이틀, 아이콘, 메뉴 |

## 게임에 넣을 리소스는?
원화를 바탕으로 만든 실제 게임용 스프라이트는 `Assets/Resources/Sprites/`에 정해진 이름으로 넣습니다.
(이름 목록은 프로젝트 루트의 README.md 참고)
