# 밸런스 시뮬레이터

`index.html` 을 더블클릭해서 브라우저로 연다 (서버 · 설치 필요 없음, 설정은 브라우저에 저장됨).

- `data.js` : 스킬 · 패시브 · 특수 강화 · 조합의 수치와 사건 순서 (게임 코드 + 노션 2026-11-23 에서 옮긴 값). 스킬을 추가하거나 특수 강화를 늘릴 때 여기만 고친다. 파일 맨 위 주석에 쓰는 법.
- `sim.js` : 엔진. 게임 피해 공식 (`Assets/Scripts/Core/Damage.cs`) 과 같은 순서로 계산하고, 화상 · 기절 · 받는 피해 증가 · 낙인 상태를 시간에 따라 추적한다.
- `index.html` : 화면.

## 들어 있는 것
- 에른 스킬 12종 (자동 6 · 수동 4 · 이동 2) 의 기본 강화 + **특수 강화 전부 (5 · 10 · 15레벨)** + **특수 조합 전부**
- 패시브 3종 (화염의 검 · 옥염 · 흡수 가열) **각각 켜고 끄기**, 기본 강화 횟수, 특수 강화 전부
- 아이템 · 세트 효과: 항목을 골라 값을 넣는 방식 (피해량 % · 최종 피해량 · 쿨타임 · 초기 피해량 · 추가 피해량 · 화상 · 지속 피해 · 기절 시간 …). 같은 세트 이름의 아이템 수가 필요 개수 이상이면 세트 효과가 켜짐. 새 항목이 필요하면 `data.js` 의 `ITEM_FIELDS` 와 `sim.js` 의 `ITEM_SUM` / `ITEM_PRODUCT` 에 한 줄씩.

## 할 수 있는 것
- 스킬 · 기본 강화 횟수 · 특수 강화 · 조합을 고르고, 모든 타이밍 · 피해 · 기절 시간 · 쿨타임 · 화상 규칙을 숫자로 바꿔 결과 확인
- "기준으로 저장" 후 값을 바꾸면 총 피해 · DPS · 처치 시간 · 화상/기절 유지율이 얼마나 변했는지 표시
- "값 훑어보기": 한 수치를 여러 값으로 바꿔 가며 비교 (예: 화상 지속시간 1~8초)
- "스킬 스펙 시트": 스킬마다 적용 피해량 % · 최종 피해량 · 1회 피해 · DPS 를 한 표로
- "기댓값 시트": 스킬마다 만들 수 있는 모든 특수 강화 조합 (+ 특수 조합) 을 전부 돌려 최소 · 중앙값 · 기댓값 · 최대 DPS 와 스킬 간 비중을 표시
- 특수 강화 · 조합 · 패시브 특수 강화의 수치 조정: 각 강화 옆 ⚙ 를 누르면 그 강화의 수치 (피해량 % · 최종 피해량 · 기절 시간 · 총 피해량 비율 · 횟수 …) 를 바로 고칠 수 있음. 바꾼 값은 모든 시트 (스킬 스펙 · 기댓값 포함) 에 적용되고 ⚙ 가 주황색으로 표시됨. 새 조정 칸을 만들려면 `data.js` 의 `sp(..., nums)` 에 `n_(이름, 기본값)` 을 넣고 cast 안에서 `NV(m, 강화id, 키)` 로 읽으면 됨
- "피해 계산기": 피해 공식을 단계별로
- 설정 복사 / 붙여넣기 (다른 PC · 기록용)

## 한계 (게임과 다른 점)
- 주 대상 1마리 + 범위 안 적 수 N 을 곱하는 방식. 위치 · 이동 · 범위가 겹치는 정도는 모델에 없고, 범위 증가는 N 으로 직접 가정
- 처치 효과 (살육의 열기 · 불길의 순환 · 죽음의 메아리 · 확산되는 불길) 는 "초당 처치 수" 로 일정하게 처치가 일어난다고 가정
- 폭발이 몇 명을 맞히는지, 추가 사용이 몇 %를 맞히는지, 화상 상태인 적 비율은 전역 설정 값으로 가정
- "총 피해량의 x% 고정 피해" 의 총 피해량 = 그 사용의 베기 최종 피해량 합 (주 대상 기준). 해석이 갈리는 곳은 `data.js` 의 note / 주석
- 이동 · 연출 · 궁극기 게이지 · 흡혈 · 이동속도 효과는 영향 없음으로 표시
- 블레이징 스톰 (궁극기) · 레니아는 아직 없음. 게임 코드가 바뀌면 `data.js` 를 수동으로 맞춰야 함
